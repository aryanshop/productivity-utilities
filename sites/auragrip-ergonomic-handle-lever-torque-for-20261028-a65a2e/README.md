# AuraGrip: Ergonomic Handle & Lever Torque Force Calculator

## Purpose
AuraGrip is a precision mechanical engineering and ergonomic workstation designed for industrial designers, product makers, and DIY engineers. It calculates lever arm forces, torque requirements, grip comfort spans, and mechanical advantage for handles, latches, handwheels, and manual tools according to standard ergonomic guidelines (ISO 11228 / MIL-STD-1472).

## Features
- **Multi-Mechanism Modeling**: Simulate straight levers, handwheel cranks, pliers/pinch grips, and spherical/wing knobs.
- **Interactive Schematic Blueprint**: Real-time vector SVG visualization showing pivot points, lever arms, grip diameters, and force vector directions.
- **Ergonomic Evaluation**: Evaluates hand fatigue thresholds against customizable operator strength percentiles (5th, 50th, 95th percentiles).
- **Unit System Support**: Switch instantly between Metric (Newtons, millimeters, Nm) and Imperial (lbf, inches, lbf·in).
- **JSON Report Export**: Save your configured parameters and engineering metrics with one click.

## Local Run Instructions
1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. No build tools, package managers, or server connections required.

## Technical Stack
- Pure vanilla HTML5, CSS3, and JavaScript (ES6+).
- Zero external dependencies, libraries, or network requests.
