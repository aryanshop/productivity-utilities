# AuraPulse: Biophilic Circadian Lighting & Color Temperature Studio

AuraPulse is an interactive biophilic lighting simulator and circadian rhythm design workbench designed for remote workers, home offices, and interior designers. It models natural daylight trajectories and artificial light spectrums to support alertness, focus, and healthy sleep architecture.

## Features

- **Room & Window Modeling**: Configure room orientation (North, East, South, West, or Windowless), floor area, and window-to-wall ratios.
- **Real-Time Solar & CCT Simulation**: Scrub through a 24-hour timeline to visualize how sunlight shifts from warm dawn (1800K) to crisp midday daylight (6500K) and warm evening dusk.
- **Melanopic EDI Calculation**: Computes equivalent daylight illuminance metrics to evaluate biological alertness and melatonin suppression.
- **Fixture Load & Dimmer Controls**: Toggle task pendants, monitor bias backlights, floor uplighters, and plant grow lights with instant wattage estimates.
- **24-Hour Profile Canvas**: Interactive HTML5 Canvas displaying circadian curves and natural sun vs. task lighting schedules.
- **Exportable Recipes**: Generate and copy professional lighting specifications for smart home or architectural planning.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, external servers, or network connections are required.

## Static Project Notice

This is a 100% static client-side web application built with vanilla HTML5, CSS3, and JavaScript. No external scripts or data collection utilities are utilized.
