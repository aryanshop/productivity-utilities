# AuraStitch: Textile Fabric Shrinkage & Yield Estimator

AuraStitch is a precision sewing, tailoring, and textile yardage calculation workbench designed for garment makers, quilters, and sustainable DIY crafters. It computes accurate fabric requirements, pre-treatment shrinkage allowances (warp and weft), pattern matching waste percentages, and grainline yield optimization.

## Features
- **Comprehensive Fabric Specifications**: Input custom fabric widths, cost per unit, warp & weft shrinkage percentages, and pattern matching or directional nap extras.
- **Dynamic Garment Components Inventory**: Add, edit, or remove pattern blocks (bodice, skirt panels, sleeves, linings) with custom dimensions and quantities.
- **Smart Yardage & Cost Calculation**: Instantly computes total cut area, required yardage/meters factoring in shrinkage multipliers, and total estimated project cost.
- **Visual Cut Layout Blueprint**: Interactive HTML5 canvas rendering a simulated fabric bolt with grainline indicators and nested pattern pieces.
- **Export / Print Cut Sheet**: One-click print support tailored for clean, ink-saving cut sheets and project notes.
- **Dual Measurement Systems**: Seamless switching between Imperial (Inches / Yards) and Metric (Centimeters / Meters).

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, compilers, package managers, or server setups required. Fully client-side and privacy-first.
