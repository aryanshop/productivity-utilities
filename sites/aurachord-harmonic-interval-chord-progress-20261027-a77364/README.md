# AuraChord: Harmonic Interval & Chord Progression Lab

## Overview
AuraChord is a professional, privacy-first music theory workbench and chord progression designer built for songwriters, producers, and musicians. It calculates diatonic chord scales across major and minor modes, provides an interactive Web Audio API synthesizer for instant audio previews, enables multi-measure chord progression sequencing, evaluates harmonic cadence and movement, and stores favorite progressions securely in local storage.

## Features
- **Diatonic Scale & Mode Generator**: Select any root note (C to B) and mode (Major, Natural Minor, Harmonic Minor, Dorian, Mixolydian, Pentatonic) to instantly compute diatonic chords and Roman numeral functions.
- **Built-in Web Audio API Synthesizer**: Preview individual chords and full multi-measure progression sequences with selectable timbres (Sine, Triangle, Sawtooth, Square).
- **Interactive Progression Timeline**: Build, test, reorder, and refine multi-measure chord sequences on the fly.
- **Harmonic Analysis Engine**: Automatically analyzes chord flow, Roman numeral structures, and cadence types (Authentic, Plagal, Half).
- **Saved Progressions Vault**: Save your favorite chord progressions locally with title tags for future songwriting sessions.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. Click "Enable Audio" to activate the Web Audio API synthesis engine and start exploring chord progressions.
