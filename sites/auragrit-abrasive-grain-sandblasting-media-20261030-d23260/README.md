# AuraGrit: Abrasive Grain & Sandblasting Media Efficiency Lab

**AuraGrit** is a precision industrial finishing and abrasive media calculation workbench designed for metalworkers, restorers, fabricators, and contractors. It computes surface preparation parameters, media consumption weight, air compressor CFM requirements, active blast pacing, and total project economic breakdowns entirely client-side.

## Features

1. **Surface Geometry Modeling**: Calculate accurate surface area for flat panels, cylindrical pipes, and spherical tanks with customizable multi-side multipliers and unit systems (Imperial & Metric).
2. **Substrate & Condition Matrix**: Factor in substrate hardness (steel, aluminum, wood, stone) and initial corrosion/coating severity (light rust, heavy mill scale, multi-layer paint, pitting).
3. **Media Efficiency Lab**: Select from Aluminum Oxide, Glass Beads, Garnet Sand, Walnut Shells, and Steel Shot with embedded consumption rates and reusability profiles.
4. **Air Compressor & Nozzle Calculator**: Determine precise CFM airflow volume required at target operating pressures across standard nozzle orifice sizes (No. 3 through No. 8).
5. **Economic Cost Distribution**: Visual cost breakdown bar indicating media material, operator hourly wages, and energy/equipment wear overheads.
6. **Session Job Logging**: Save, review, and export calculation estimates in a responsive local session table.

## Local Run Instructions

1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, external servers, package managers, or internet connection are required.

## Technology Stack

- **HTML5**: Semantic, accessible document markup.
- **CSS3**: Modern Flexbox/Grid responsive layouts, CSS variables, dark industrial styling.
- **Vanilla ES6 JavaScript**: Pure client-side arithmetic modeling and interactive DOM updates.
