# AuraVellum: Typographic Grid & Baseline Rhythm Laboratory

## Overview
AuraVellum is a precision typography layout and vertical rhythm workstation designed for web designers, typographers, and frontend developers. It provides instant calculation of modular type scales, vertical baseline grid alignment, container column widths, and character measure limits.

## Features
- **Modular Type Scaling**: Experiment with standard harmonic ratios (Minor Second, Major Third, Perfect Fourth, Golden Ratio, etc.).
- **Vertical Rhythm Grid**: Toggleable baseline grid overlay to test rhythm consistency across headings, body copy, and blockquotes.
- **Measure & Character Count**: Real-time measurement of characters per line (ch) to ensure optimal reading ergonomics.
- **CSS Code Synthesizer**: Automatically generates modern CSS custom properties (`:root`) corresponding to your active layout settings.
- **Preset Manager**: Local-first storage system to save, load, and manage custom typography presets.
- **Preview Stage**: Fully interactive article preview with light/dark theme toggles.

## Local Run Instructions
1. Download or clone the project files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` in any modern web browser.
3. This is a fully static client-side web application with zero external dependencies or server requirements.

## Technology Stack
- Vanilla HTML5
- Vanilla CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6+)
- LocalStorage API for preset persistence
