# PaceCraft: Endurance Split & Race Fuel Strategist

## Purpose
PaceCraft is a precision race-day planning and nutrition strategy utility designed for runners, marathoners, and endurance athletes. It helps athletes plan split paces, visualize elevation & pacing profiles, calculate caloric expenditure, and schedule exact energy gel and fluid intake intervals.

## Features
- **Multiple Race Presets:** Choose from 5K, 10K, Half Marathon, Marathon, or custom distances.
- **Flexible Pacing Strategies:** Calculate Even splits, Negative splits, Positive splits, or Hilly terrain profiles.
- **Nutrition & Fuel Scheduler:** Automatically computes total carbohydrate requirements, energy gel counts, and fluid intake schedules based on body weight and duration.
- **Interactive Canvas Chart:** Visualizes segment pacing alongside simulated elevation profiles and fuel stations.
- **Printable Cheat Sheet:** Clean print layout optimized for wristbands or race bib attachments.
- **100% Client-Side:** Privacy-first tool running entirely in the browser without external servers or tracking.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.

## Static Project Note
This project is fully self-contained using vanilla HTML5, CSS3, and modern JavaScript with no external dependencies or backend requirements.
