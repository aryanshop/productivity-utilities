# AuraCalc: Projectile Motion & Trajectory Simulation Laboratory

AuraCalc is a precision physics trajectory and projectile motion simulation laboratory designed for students, educators, game developers, and physics hobbyists. Built with vanilla HTML5 Canvas, modern CSS, and lightweight JavaScript, it offers a fully responsive and interactive workspace.

## Features

- **Interactive Launch Controls**: Adjust initial velocity, launch angle, and initial height with real-time feedback.
- **Celestial Gravity & Air Resistance**: Simulate trajectories across different celestial bodies (Earth, Moon, Mars, Jupiter) or custom gravity, alongside configurable aerodynamic drag coefficients ($C_d$), projectile mass, and cross-sectional area.
- **HTML5 Canvas Visualization**: Smooth trajectory rendering with apex and impact markers, grid lines, and pan/zoom controls.
- **Real-time Metrics**: Instantly computes max height, total flight time, maximum range, and impact velocity.
- **Local-First Presets & CSV Export**: Save custom simulation setups to local storage and export raw trajectory time-step data as CSV.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build step, external dependencies, or internet connection required.
