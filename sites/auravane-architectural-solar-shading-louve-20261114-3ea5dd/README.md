# AuraVane: Architectural Solar Shading & Louver Geometry Laboratory

## Purpose
AuraVane is a precision architectural solar shading and louver geometry calculator designed for architects, sustainable building designers, and passive solar engineering enthusiasts. It computes optimum overhang depths, vertical fin projections, and louver slat tilt angles based on site latitude, orientation, and seasonal solar trajectories.

## Features
- **Interactive Solar Path Modeling:** Renders dynamic solar altitude and azimuth arcs for summer solstice, equinox, and winter solstice directly onto an HTML5 Canvas stereographic coordinate grid.
- **Passive Shading Optimization:** Instantly calculates required horizontal overhang projections and louver angles to minimize peak cooling loads.
- **Local Storage Preset Management:** Save and recall custom architectural profiles directly in your browser's local storage.
- **Comprehensive Specification Generator:** Automatically formats detailed architectural design notes and shading coefficient estimates.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, external servers, package managers, or internet connection are required.

## Static Project Statement
This application is 100% client-side with zero external network requests, third-party libraries, analytics, or trackers.
