# AuraVane: Air Flow & Duct Friction Head Loss Laboratory

AuraVane is a precision HVAC ductwork sizing and static pressure friction loss calculator designed for mechanical engineers, ventilation contractors, and DIY home renovators.

## Features
- **Airflow & Duct Sizing**: Configure CFM, round diameters, or rectangular duct dimensions.
- **Material Roughness Profiles**: Select galvanized steel, aluminum spiral, flexible duct, PVC, or fiberglass duct board.
- **Fittings & Equivalent Lengths**: Account for 90° and 45° elbows, branch tees, and grilles/dampers.
- **Hydraulic Calculations**: Instantly computes air velocity (FPM), friction loss rate (in. w.g. / 100 ft), equivalent length, Reynolds number, and total static pressure drop.
- **Interactive Canvas Pressure Profile**: Real-time hydraulic gradient chart visualizing pressure drop along the run.
- **Preset Library & Report Export**: Load standard residential and commercial presets or export professional reports as text.

## Local Run Instructions
Clone or download the repository and open `index.html` in any modern web browser.

## Technology Stack
- Pure Vanilla HTML5, CSS3, and JavaScript.
- Zero external dependencies, build tools, or frameworks.
