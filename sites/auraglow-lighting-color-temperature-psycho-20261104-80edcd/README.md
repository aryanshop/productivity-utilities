# AuraGlow: Lighting Color Temperature & Psychological Mood Lab

AuraGlow is an interactive interior lighting color temperature (Kelvin), CRI, and psychological mood workstation designed for interior designers, remote workers, architects, and home stagers.

## Features

- **Activity & Room Configuration**: Tailor lighting recommendations based on specific room types (Office, Bedroom, Kitchen, Living Room) and activity goals (Deep Focus, Creative Brainstorming, Relaxation, Social Dining).
- **Spectrum Tuning Sliders**: Adjust Color Temperature (1800K to 6500K), Total Fixture Lumens, and Color Rendering Index (CRI Ra) with real-time feedback.
- **Psychological Mood & Circadian Metrics**: Instantly calculates lux levels, melanopic equivalent daylight illuminance (mEDI), estimated LED power load, and psychological mood impact.
- **Interactive Visual Spectrum Simulator**: HTML5 Canvas rendering of the relative spectral distribution curve paired with an ambient glow preview swatch.
- **Local Persistence & JSON Export**: Save lighting setups to local storage and export archives securely client-side.

## Local Run Instructions

1. Download or clone repository files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` directly in any modern web browser.
3. No build tools, external servers, or network connections required.

## Static Project Statement
This project is 100% client-side and standalone. No data is transmitted externally.
