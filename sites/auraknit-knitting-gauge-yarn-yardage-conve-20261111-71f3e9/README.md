# AuraKnit: Knitting Gauge & Yarn Yardage Conversion Laboratory

AuraKnit is a precision knitting and fiber arts calculator designed for knitters, crocheters, and indie dyers. It calculates exact project yardage, stitch counts, required skeins, and yarn substitution comparisons based on custom gauge swatch measurements.

## Features
- **Gauge & Swatch Calculator**: Computes stitch and row densities per inch from 4-inch (10cm) swatch metrics.
- **Garment Dimension Scaling**: Estimates total cast-on stitches, working rows, and linear yardage requirements.
- **Skein & Weight Estimation**: Computes total skeins needed including customizable safety and swatch buffers.
- **Yarn Weight Substitution Matrix**: Instantly projects required yardage when switching between yarn weight categories (Lace to Super Bulky).
- **Local-First Presets**: Save and reload project calculations securely in browser local storage without server interaction.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No installation or build steps required.

## Technology Stack
- Vanilla HTML5, CSS3, and JavaScript (ES6+)
- Local Storage API for client-side persistence
- Fully responsive layout optimized for desktop and mobile devices
