# ZenithGoal: Habit Loop & Micro-Milestone Architect

ZenithGoal is an interactive personal productivity tool designed to bridge the gap between intimidating long-term ambitions and daily actionable steps.

## Purpose & Features
- **Master Ambition Blueprinting:** Define core life and professional goals with clear timelines and motivations.
- **Micro-Milestone Decomposition Tree:** Break goals down across execution phases (Foundation, Momentum, Mastery) with impact and effort tagging.
- **Daily Habit Loop Tracker:** Attach triggers to daily habits and build streaks with satisfying interactive feedback.
- **Energy & Impact Matrix:** Automatically categorize tasks into Quick Wins, Major Projects, Fill-Ins, and Time-Wasters for optimal prioritization.
- **Local Persistence & Backup:** Fully privacy-first with local storage saving, JSON export, and import support.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser.

## Static Project Note
This is a purely static front-end web application built with vanilla HTML, CSS, and JavaScript. No external build steps, backend servers, or third-party libraries are required.
