# AuraCalc: Kitchen Knife Sharpening Geometry & Bevel Laboratory

AuraCalc is a precision kitchen knife sharpening geometry, bevel angle, and abrasive grit progression workbench designed for culinary professionals, home cooks, and sharpening enthusiasts.

## Features
- **Blade Profile Configurations**: Instantly switch between Western Chef's knives, Japanese Santokus, Paring knives, Sujihikis, and Heavy Cleavers or configure custom spine thicknesses and bevel angles.
- **Interactive Canvas Cross-Section**: Real-time rendering of the blade bevel, spine, primary taper, and cutting apex.
- **Advanced Metrics**: Calculates bevel width, total included angle, estimated apex radius (microns), and estimated metal removal volume.
- **Abrasive Grit Progression**: Simulate grit progressions from 220 coarse stones up to 12,000 polishing stones.
- **Local Session Logging**: Keep track of sharpening protocols, export logs as JSON backups, and review session history locally.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enjoy a fully offline, privacy-first sharpening laboratory experience.
