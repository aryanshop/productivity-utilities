# AuraSlate: Freelance Project Scope & Milestone Cost Estimator

AuraSlate is a precision project scoping, budgeting, and milestone cost estimation workbench built for freelancers, consultants, and agencies. It enables professionals to build detailed project estimates by balancing hourly rates, complexity multipliers, contingency safety buffers, and phase-by-phase time breakdowns.

## Key Features

1. **Dual Pricing Strategy Support**: Switch between hourly-rate calculations and value/fixed-scope pricing models with customizable complexity multipliers and safety buffers.
2. **Dynamic Project Phases**: Add, edit, or remove project phases (Discovery, Design, Development, QA, Deployment) with assigned team roles and estimated hours.
3. **Milestone Payment Schedule**: Automatically split total project costs into structured client payment milestones with live dollar conversions.
4. **Visual Phase Distribution Chart**: Interactive HTML5 Canvas chart rendering workload distribution across project stages.
5. **Proposal Statement Generator**: Instantly generate a polished, client-ready proposal summary statement with one-click clipboard copying.
6. **Local Backup & Restore**: Export and import project scoping templates as JSON files with zero external dependencies or server requirements.

## Local Run Instructions

1. Download or clone all repository files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enjoy a 100% client-side, privacy-first utility.

## Technology Stack

- Pure HTML5, CSS3, and Vanilla JavaScript (ES6+).
- No external frameworks, libraries, fonts, or tracking scripts.
