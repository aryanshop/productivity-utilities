# AuraPinch: Bonsai Pot Proportions & Soil Drainage Laboratory

AuraPinch is a precision bonsai styling, pot proportion calculation, and soil drainage laboratory designed for bonsai artists, horticulturists, and plant enthusiasts.

## Features

1. **Aesthetic Proportion Calculator**: Input tree height, trunk caliper, canopy spread, and bonsai style (Formal Upright, Informal Upright, Sloping, Cascade, Literati) to calculate optimal pot length, depth, shape, and planting offset according to classical horticultural aesthetics.
2. **Interactive Visual Studio**: Real-time HTML5 Canvas preview rendering the bonsai silhouette, proportional pot bounds, and foliage pads.
3. **Soil Hydraulic & Nutrient Mixer**: Blend Akadama, Pumice, Lava Rock, and Organic Compost to analyze drainage rate, water retention capacity, and Cation Exchange Capacity (CEC).
4. **Local Storage Preset Vault**: Save and recall your favorite tree configurations and soil recipes securely in your browser.

## Local Run Instructions

Since this project is entirely static (HTML5, CSS3, Vanilla JavaScript), no build tools or servers are required:

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.

## Privacy

100% client-side. No tracking, analytics, or external server calls are made.
