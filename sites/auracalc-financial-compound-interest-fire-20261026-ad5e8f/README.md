# AuraCalc: Financial Compound Interest & FIRE Retirement Planner

## Purpose
AuraCalc is a precision FIRE (Financial Independence, Retire Early) and wealth accumulation calculator designed to help users model compound investment growth, plan savings rates, and visualize their journey toward financial independence.

## Features
- **Real-Time Simulation Engine**: Instantly recalculates net worth trajectory as you adjust age, income, savings rate, and expected investment returns.
- **FIRE Corpus Calculation**: Automatically calculates your financial independence target using the legendary 4% Safe Withdrawal Rule.
- **Interactive Canvas Chart**: Renders a smooth wealth growth curve, total contributions, and FIRE target thresholds.
- **Year-by-Year Milestone Ledger**: Detailed breakdown table tracking age, starting balance, annual contributions, investment returns, and FIRE achievement status.
- **CSV Export**: Export your complete projection ledger for offline spreadsheet analysis.
- **Privacy First**: 100% client-side calculation using vanilla JavaScript. No data ever leaves your browser or gets stored on external servers.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Adjust sliders and input fields to customize your retirement simulation.

## Technology Stack
- HTML5, CSS3, JavaScript (ES6+)
- HTML5 Canvas API for responsive charting
- Zero external dependencies, libraries, or network requests.
