# AuraGrit: Abrasive Grain & Sandblasting Media Efficiency Lab

## Overview
AuraGrit is a professional, client-side industrial finishing and abrasive media calculator designed for metalworkers, restorers, fabricators, and coating technicians. It computes accurate material consumption weights, pneumatic compressor CFM requirements, nozzle velocity ratings, media recycling thresholds, and comprehensive project cost breakdowns.

## Key Features
- **Surface Geometry Engine**: Calculate precise surface areas for flat plates, cylindrical tanks/pipes, and complex structural profiles with customizable side counts and profile complexity factors.
- **Substrate & Coating Calibration**: Adjust for base materials (Structural Steel, Aluminum, Hardwood, Stone) and coating conditions (SSPC surface preparation standards from light mill scale to heavily pitted corrosion).
- **Abrasive Media Lab**: Select from Garnet, Aluminum Oxide, Glass Bead, Walnut Shell, and Steel Shot with automatic density, Mohs hardness, and recycling cycle insights.
- **Pneumatic & Compressor Calculator**: Determine minimum required compressor CFM and nozzle exit velocities based on orifice size (#3 through #8) and working pressure (80-110 PSI).
- **Financial & Lifecycle Breakdown**: Estimate material costs, direct labor rates, equipment overhead, and visualize virgin vs. recycled media breakdown.
- **Printable Job Sheet**: Clean print stylesheet formatted for workshop job reports.

## Local Run Instructions
1. Download or clone repository files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` in any modern web browser.
3. Fully offline-capable with zero external dependencies or network requests.
