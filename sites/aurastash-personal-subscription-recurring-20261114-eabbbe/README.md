# AuraStash

AuraStash is a precision personal subscription and recurring expense budget laboratory designed for freelancers, remote workers, and budget-conscious individuals who prioritize local-first privacy.

## Features

- **Comprehensive Analytics Dashboard**: Instantly tracks Monthly Run-Rate, Annualized Burn, Average Cost per Active Item, and Review/Optimization Potential.
- **Flexible Billing Cycles**: Supports Monthly, Annual, Quarterly, and Weekly recurring payment frequencies with automatic monthly equivalent conversions.
- **Interactive Spending Breakdown**: Custom HTML5 Canvas donut chart visualizing spending distribution across categories (Software, Utilities, Entertainment, Cloud, Memberships).
- **Advanced Filtering & Search**: Filter by category or active status, and search in real-time.
- **Local-First Security**: All records are saved locally in browser `localStorage`. No external servers or cloud dependencies.
- **JSON Backup & Restore**: Easily export and import your workspace data as secure JSON files.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.

## Technical Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- No external frameworks, build tools, or network requests.
