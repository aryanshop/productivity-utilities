# AuraFrost: Refrigeration & Thermal Heat Load Laboratory

AuraFrost is a professional, client-side thermal engineering and refrigeration load calculator built for HVAC technicians, cold storage builders, food service planners, and thermodynamics students.

## Key Features
- **Comprehensive Heat Gain Calculation**: Computes transmission loads (walls, ceiling, floor), product pulldown and respiration loads, infiltration loads (door openings), internal lighting, and personnel heat dissipation.
- **Compressor Sizing & Capacity**: Instantly calculates required compressor horsepower (HP), Tons of Refrigeration (TR), and Sensible-to-Latent Heat Ratios (SHR).
- **Interactive Canvas Breakdown Chart**: Real-time donut chart visualizing heat gain components and percentage shares.
- **Preset Scenarios**: Quick-load templates for Restaurant Walk-In Coolers, Commercial Freezers, Florist Preservation Rooms, and Brewery Cellars.
- **Engineering Report Exporter**: Generates a clean text-based engineering summary report ready for clipboard export.
- **Unit Flexibility**: Toggle seamlessly between Imperial (BTU/hr, °F, ft) and Metric (kW, °C, meters).

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No server setup, external dependencies, or build tools required (fully offline static web app).

## Technology Stack
- Vanilla HTML5, CSS3, and JavaScript (ES6+).
- HTML5 Canvas API for real-time graphical visualization.
- 100% Client-side execution with local privacy.
