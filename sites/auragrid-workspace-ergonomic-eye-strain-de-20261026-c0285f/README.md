# AuraGrid: Workspace Ergonomic Eye-Strain & Desk Lighting Optimizer

AuraGrid is a browser-based precision workspace utility designed for remote workers, developers, and designers to calculate, evaluate, and optimize desk illumination, display luminance, and circadian lighting schedules.

## Features
- **Ergonomic Contrast Calculator**: Evaluates screen-to-wall luminance ratios against ISO/CIE ergonomic recommendations to eliminate glare and pupil fatigue.
- **Eye Fatigue Risk Scoring**: Computes a dynamic strain score based on ambient room lux, monitor nits, and wall reflectance.
- **Interactive Setup Simulation**: Real-time canvas rendering of monitor illumination, rear wall reflectance, and LED bias backlighting.
- **Circadian Lighting Profile**: Generates a 24-hour biological timeline with color temperature (CCT) recommendations to protect melatonin synthesis during evening hours.
- **Local Persistence**: Saves your workspace configuration locally in your browser so your preferences are preserved across sessions.

## Local Run Instructions
1. Download or clone the project repository.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No server setup, external APIs, or build tools are required.

## Technology Stack
- Pure HTML5, CSS3, and Vanilla JavaScript.
- Responsive CSS Grid and Flexbox layouts.
- HTML5 Canvas for real-time visual simulations.
