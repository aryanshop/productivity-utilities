# AuraPack: Backpack Travel Weight & Volume Packing Optimizer

AuraPack is a local-first travel gear and ultralight packing utility designed for backpackers, digital nomads, and hikers. It helps users manage their packing inventory, calculate base weights vs. skin-out weights, inspect volume capacities, and avoid airline baggage limits or heavy pack discomfort.

## Features

- **Inventory & Category Management**: Organize items across Clothing, Sleep & Shelter, Electronics, Toiletries, Gear, and Consumables.
- **Weight & Volume Calculators**: Track individual quantities, weights (grams/kg or lbs/oz), and backpack volume in Liters.
- **Base Weight Computation**: Automatically separates backpack contents from worn items and consumable supplies.
- **Visual Weight Distribution**: Interactive category breakdown bars show where your pack weight is concentrated.
- **Local Persistence & JSON Backup**: All data is securely stored in your browser's `localStorage` with one-click export and import capabilities.

## Local Run Instructions

1. Download or clone the project folder containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No server setup, compilation, or external dependencies required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- No external frameworks, libraries, or network requests.
