# ChromaTune: Harmonic Color Palette & Contrast Matrix Studio

ChromaTune is a professional browser-based color suite and WCAG accessibility contrast workbench designed for UI designers and front-end developers. It enables instant generation of color palettes following classic color harmony rules, evaluates contrast ratios across a complete accessibility matrix, simulates color vision deficiencies, and offers a live component sandbox.

## Features
- **Harmonic Color Generation**: Create complementary, analogous, triadic, split-complementary, and monochromatic palettes from any base color.
- **Interactive Shades**: Adjust palette step counts dynamically from 3 to 9 swatches.
- **WCAG Contrast Matrix**: Inspect full cross-contrast ratios and compliance badges (WCAG AA / Fail) for every combination of text and background.
- **Color Vision Deficiency Simulation**: Simulate Protanopia, Deuteranopia, Tritanopia, and Achromatopsia across swatches and contrast matrices in real time.
- **UI Component Sandbox**: Test active palette colors instantly on buttons, badges, and notification banners.
- **Code Export**: Instantly export clean CSS Custom Properties or JSON palette objects.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No external build tools, package managers, or server connections are required.

## Static Project
This is a fully self-contained front-end application built with vanilla HTML5, CSS3, and modern JavaScript. All color calculations, accessibility checks, and simulations execute locally in your browser.
