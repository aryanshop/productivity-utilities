# AuraSlate: Micro-Budget & Cash Flow Runway Forecaster

## Purpose
AuraSlate is a precision personal finance and micro-business financial runway calculator designed to help freelancers, indie creators, and small team leads project cash reserves, evaluate monthly burn rates, and stress-test financial resilience against income shocks.

## Features
- **Liquid Cash & Runway Calculator**: Computes exact months of runway remaining based on current reserves and net burn.
- **Dynamic Income & Expense Items**: Add, edit, and remove multiple income streams and fixed expense categories.
- **Stress-Test Scenario Slider**: Instantly simulate a -50% to +50% shock in monthly earnings and visualize the ripple effect.
- **12-Month Projection Canvas Chart**: Real-time graphical trajectory plotting normal vs. stress-tested cash reserves.
- **Local Data Persistence**: Automatically saves your setup locally via `localStorage`.
- **JSON Backup & Restore**: Export your financial setup to a JSON file or import backups instantly.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` in any modern web browser.
3. That's it! No build tools, external servers, or network connection required.

## Technology Stack
- Pure HTML5, CSS3, and Vanilla JavaScript.
- HTML5 Canvas for data visualization.
- 100% client-side execution with zero external data collection or tracking.
