# AuraCalc: Compound Interest & Inflation Wealth Simulator

## Purpose
AuraCalc is a precision wealth accumulation and inflation-adjusted retirement growth simulator designed for long-term investors, planners, and savers. It models compounding growth over multi-decade horizons while accounting for recurring contributions, tax drag, and purchasing power erosion due to inflation.

## Features
- **Comprehensive Parameter Control**: Adjust initial principal, monthly savings rate, expected annual returns, inflation rate, tax drag, and time horizon up to 80 years.
- **Dual Tracking**: Calculates both nominal balances and real purchasing power (inflation-adjusted).
- **Interactive Canvas Chart**: Responsive multi-year compounding chart with hover tooltips and visual trend lines.
- **Detailed Amortization Breakdown Table**: Year-by-year summary of total principal, interest earned, and ending balances.
- **Local-First Persistence**: Automatically saves your inputs in `localStorage` across sessions.
- **CSV Export**: Instantly export your full simulation dataset for spreadsheet analysis.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser, or serve it via a local static server (e.g., `npx serve` or Live Server).

## Static Project Note
This application is built with 100% vanilla HTML5, CSS3, and JavaScript. No external libraries, frameworks, or backend network calls are used.
