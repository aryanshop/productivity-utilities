# AuraVane: Architectural Wind Pressure & Aerodynamic Drag Calculator

## Overview
AuraVane is a precision architectural and structural wind load analysis laboratory designed for architects, structural engineers, builders, and physics students. It provides real-time computations of velocity pressure, design wind pressure, total aerodynamic drag force, and overturning moments based on building geometry, terrain exposure, and wind velocity.

## Features
- **Interactive Parameter Controls**: Adjust basic wind speed, building height, width, length, roof pitch, topographic factor, and terrain category.
- **Live Metric Calculations**: Instantly computes velocity pressure ($q_z$), design wind pressure, total drag force, and overturning moments.
- **Unit Switcher**: Toggle instantly between US Imperial (mph, ft, psf, lbs) and SI Metric (km/h, m, Pa, N) units.
- **HTML5 Canvas Flow Visualizer**: Renders a dynamic vector graphic illustrating wind streamlines, positive windward pressure, and leeward/roof suction forces.
- **Local Simulation Log**: Save simulation results into an interactive log table for easy comparison.
- **Client-Side & Privacy-First**: Zero external dependencies, fonts, tracking, or network requests.

## Local Run Instructions
1. Download or clone the project files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` in any modern web browser.
3. Adjust sliders and input fields to explore aerodynamic structural behaviors.

## Technology Stack
- Pure HTML5, CSS3, and Vanilla JavaScript (ES6+).
- HTML5 Canvas API for real-time aerodynamic flow visualization.
