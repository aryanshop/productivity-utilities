# AeroGrid: Workspace Desk Cable & Power Load Optimizer

AeroGrid is a client-side productivity and power-management utility designed for developers, remote workers, and hardware enthusiasts to calculate, organize, and optimize their desk power loads, surge protector capacity, electricity costs, and cable routing.

## Features

- **Circuit & Electrical Calculation**: Computes total active wattage, current draw (Amps) against standard circuit breaker limits (120V / 230V / 100V), and evaluates safe surge protector thresholds.
- **Energy & Cost Estimation**: Projects monthly electricity usage in kWh and estimated utility costs based on customizable daily usage hours and local electricity rates.
- **Hardware Inventory Manager**: Add, edit, and categorize monitors, towers, audio interfaces, chargers, and peripherals with individual power ratings and AC plug counts.
- **Cable Length & Routing Visualizer**: Interactive canvas visualizer showing cable run lengths radiating from a central power strip hub.
- **Presets & Data Portability**: Instant presets for Minimalist, Gaming, and Video Editing setups, plus local JSON export and import capabilities.
- **Local-First**: All data is securely stored locally in your browser via `localStorage`.

## Local Run Instructions

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.
3. No build step, compilation, or web server required.
