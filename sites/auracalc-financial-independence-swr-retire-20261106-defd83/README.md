# AuraCalc: Financial Independence & SWR Retirement Laboratory

AuraCalc is a precision financial independence, retire-early (FIRE), and safe withdrawal rate (SWR) simulation workbench designed for personal finance planners, indie makers, and early retirees.

## Features

- **FIRE & SWR Simulation**: Compute exact years to financial independence based on net worth, income, expenses, and expected real returns.
- **Interactive Wealth Trajectory Chart**: HTML5 Canvas rendering multi-decade portfolio growth curves and FIRE thresholds.
- **Milestone Breakdown**: Automatic tracking of Emergency Funds, Lean FIRE, Standard FIRE, and Fat FIRE targets.
- **Local-First & Privacy**: All configurations persist locally in your browser storage without any external servers or telemetry.
- **Backup & Restore**: Export and import your retirement profile securely via local JSON files.

## Local Run Instructions

1. Download or clone the project repository.
2. Open `index.html` in any modern web browser.
3. Adjust your financial parameters and click **Run Simulation** or modify values in real-time.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and ES6 JavaScript.
- Responsive CSS Grid and Flexbox layout.
- Native HTML5 Canvas 2D Context for interactive financial charting.
