# AeroGrid: Workspace Desk Cable & Power Load Optimizer

AeroGrid is a client-side productivity utility designed for remote workers, developers, and desktop setups to plan and optimize hardware power loads, circuit safety thresholds, and desk cable routing.

## Features

- **Hardware Inventory Management**: Add, edit, and categorize workstation equipment (monitors, laptops, audio interfaces, chargers, lighting).
- **Real-time Power & Cost Calculations**: Computes total active wattage, current draw in Amps across 120V or 230V circuits, and estimates monthly electricity bills based on custom kWh rates and daily usage hours.
- **Circuit Safety Analyzer**: Live progress indicators and warning badges evaluating your setup against standard 15A / 13A household circuit limits.
- **Cable Routing Intelligence**: Estimates total cord lengths and analyzes individual slack buffers based on different routing methods (direct drop, under-desk trays, or perimeter legs).
- **Backup & Export**: Export your complete workspace configuration as clean JSON or import previous backups instantly.

## Local Run Instructions

Simply download or clone the repository and open `index.html` in any modern web browser. No build steps, external servers, or package installations required.

## Privacy

All data is stored locally in your browser using `localStorage`. No data is ever transmitted or collected.
