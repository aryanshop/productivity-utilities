# AuraGrit: Abrasive Sandblasting & Media Consumption Lab

AuraGrit is a professional, client-side surface preparation and industrial finishing calculator designed for metalworkers, restorers, woodworkers, and fabricators.

## Features
- **Abrasive Consumption Estimation:** Computes precise media weight requirements based on surface material hardness, coating contamination, and media density.
- **Equipment & Air Requirements:** Calculates recommended compressor CFM at target working PSI, nozzle orifice velocity, air hose diameter, and receiver tank capacity.
- **Media Recycling Analysis:** Evaluates media durability and recycling thresholds across Garnet, Aluminum Oxide, Glass Bead, Walnut Shell, and Steel Grit.
- **Visual Proportion Breakdown:** Renders a clean canvas visual throughput chart.
- **Job Sheet Printing:** Cleanly formatted print layout for shop floor documentation.

## Local Run Instructions
1. Download or clone repository files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` in any modern web browser.
3. Completely client-side and offline-capable.
