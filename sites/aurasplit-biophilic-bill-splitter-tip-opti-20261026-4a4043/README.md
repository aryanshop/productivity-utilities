# AuraSplit: Biophilic Bill Splitter & Settlement Lab

AuraSplit is a privacy-first group expense fairness engine and settlement strategist built with vanilla HTML5, CSS3, and modern JavaScript. Designed for dinners, trips, and shared living expenses.

## Features

- **Participant Management**: Add and manage group members dynamically with chip tags and automatic cleanup.
- **Flexible Expense Logging**: Record shared bills with equal split or customized proportional weight allocations.
- **Tax & Tip Optimisation**: Instantly adjust service fees, sales tax percentages, and custom gratuity sliders across the entire bill total.
- **Automated Settlement Algorithm**: Computes exact individual balances (paid vs. owed) and generates the minimum number of cash transfers required to settle all debts.
- **Interactive SVG Debt Network Graph**: Visually inspect who owes whom through a live rendered network topology.
- **Local Persistence & JSON Backup**: Automatically saves session data to `localStorage` with one-click JSON file export and import capabilities.
- **Zero External Dependencies**: Fully self-contained, client-side application with no external network requests or tracking.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Start adding participants and logging expenses!
