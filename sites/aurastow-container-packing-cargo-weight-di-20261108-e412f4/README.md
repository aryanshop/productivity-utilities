# AuraStow: Container Packing & Cargo Weight Distribution Laboratory

AuraStow is a precision cargo packing, container stowage, and weight distribution calculator designed for van lifers, overlanders, boat owners, and road trippers.

## Features
- **Container Specification Setup**: Configure vehicle or cargo box dimensions (length, width, height) and maximum payload weight limits.
- **Gear Item Management**: Add cargo items with precise dimensions, weights, categories (heavy water/power, kitchen, gear, clothing, safety), access priorities, and fragility flags.
- **Real-Time Payload & Volume Metrics**: Instant calculations of total weight, volume utilization percentages, and dynamic weight status indicators.
- **Center of Gravity Balance Analysis**: Evaluates load distribution to help prevent hazardous axle overload or unstable handling.
- **Interactive Visualizer Canvas**: Top-down plan view and side profile cargo bay mapping with categorized color-coded blocks.
- **Local Persistence**: Automatically saves your trip setup and inventory locally in your browser.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. No server setup, external dependencies, or build tools required.

## Technology Stack
- Pure Vanilla HTML5, CSS3, and JavaScript.
- Responsive design with CSS Grid and Flexbox.
- HTML5 Canvas 2D graphics rendering.
- Zero external libraries, trackers, or network calls.
