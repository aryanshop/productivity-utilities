# ZenFlow: Mindful Breathing & Somatic Coherence Studio

ZenFlow is a polished, client-side productivity and wellness utility designed to help remote professionals, students, and mindful practitioners regulate their nervous systems through guided breathing techniques and somatic pacing.

## Features
- **Multiple Science-Backed Presets**: Box Breathing, 4-7-8 Relaxation, Coherent Breathing (HRV balance), and Energizing Breath.
- **Fluid Visualizer**: Smooth CSS transform animations synchronized with real-time countdown timers and glowing particle orbs.
- **Ambient Acoustic Cues**: Optional gentle frequency tones generated using the Web Audio API for eyes-closed practice.
- **Session Ledger & Reflections**: Track completed sessions, total minutes breathed, and record personal post-session reflection notes locally in browser storage.
- **Privacy First**: Zero tracking, completely static, and runs entirely offline.

## Local Run Instructions
1. Download or clone the repository.
2. Open `index.html` directly in any modern web browser.
