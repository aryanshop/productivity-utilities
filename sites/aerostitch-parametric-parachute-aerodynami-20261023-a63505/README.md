# AeroStitch: Parametric Parachute & Aerodynamic Decelerator Designer

## Purpose
AeroStitch is a precision engineering utility designed for rocketeers, modelers, and recovery system architects. It calculates exact parachute canopy dimensions, surface areas, gore panel layouts, and shroud requirements based on payload mass and target touchdown velocity using core aerodynamic drag physics.

## Features
- **Flight Parameter Modeling**: Configure payload mass, target descent speed, and atmospheric altitude density.
- **Canopy Architecture Options**: Select Hemispherical, Flat Circular, Annular, or Cruciform designs with automatic Drag Coefficient ($C_d$) adjustment.
- **Interactive Blueprint Visualizer**: Real-time SVG rendering of single gore cutting templates and top assembly schematics.
- **Fabric Cut List & Material Breakdown**: Automated sizing for gores, shroud lines, shock cords, and apex reinforcement patches.
- **Print & Export Ready**: Clean specification sheet generator formatted for printing or PDF export.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No installation, build tools, or network connection required.

## Technology Stack
- Pure Vanilla HTML5, CSS3, and ES6 JavaScript.
- Responsive CSS Grid / Flexbox layout.
- Native SVG rendering for dynamic technical diagrams.
