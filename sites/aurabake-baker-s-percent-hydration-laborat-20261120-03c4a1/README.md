# AuraBake: Baker's Percent & Hydration Laboratory

AuraBake is a precision artisan baking formula calculator and baker's percentage workbench designed for sourdough bakers, pastry chefs, and home bread enthusiasts.

## Features

- **Baker's Percentage Engine**: Dynamically calculates exact gram or ounce weights based on total flour mass or total final dough weight.
- **True Hydration & Levain Math**: Accounts for water and flour contributions from sourdough levain to compute true dough hydration percentages.
- **Water Temperature Calculator (RAFT Formula)**: Computes ideal strike water temperatures based on desired dough temperature (DDT), room temp, flour temp, and friction factor.
- **Estimated Baking Timeline**: Automatically generates a step-by-step schedule from autolyse to cold retard and baking.
- **Local Recipe Storage**: Save, load, and manage custom recipes using browser localStorage without external databases or tracking.
- **Preset Library**: Quickly load classic sourdough, brioche, Neapolitan pizza dough, and sandwich loaf presets.
- **JSON Export**: Export your complete baking formula for sharing or offline backup.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enjoy a 100% client-side, privacy-focused artisan baking workbench.

## Technical Stack

- Vanilla HTML5, CSS3, and JavaScript (ES6+).
- No external frameworks, build tools, or network requests.
