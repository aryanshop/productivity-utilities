# AeroVent: HVAC Room Airflow & Ventilation Calculator

AeroVent is an interactive room ventilation and air change rate (ACH) calculation utility designed for homeowners, indoor air quality (IAQ) enthusiasts, and HVAC designers. It calculates required CFM, recommended air changes per hour based on ASHRAE standards, and air purifier Clean Air Delivery Rates (CADR).

## Features

- **ASHRAE-aligned ACH standards**: Predefined profiles for offices, bedrooms, kitchens, bathrooms, and workshops.
- **Dynamic Airflow Calculations**: Computes precise cubic feet per minute (CFM) requirements based on room dimensions, occupant counts, and odor/smoke factors.
- **Interactive Air Dynamics Visualizer**: HTML5 canvas animation displaying particle circulation between supply and exhaust vents.
- **Purifier CADR Estimator**: Calculates recommended HEPA air purifier CADR targets for high-allergy environments.
- **Local Storage Ledger**: Save, load, and manage custom room configurations directly in browser storage.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Adjust room dimensions and parameters to calculate live ventilation targets.

*Note: This is a static client-side project requiring no external build tools, backend servers, or internet connection.*
