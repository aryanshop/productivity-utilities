# ChronoKnit: Time-Block & Sleep Circadian Synchronization Planner

ChronoKnit is a privacy-first local web application designed to help remote workers, students, and professionals align their daily time-blocking schedules with natural circadian rhythms and biological sleep cycles.

## Features
- **Circadian Energy Wave Visualizer**: Interactive canvas renders a 24-hour biological energy curve matching your chronotype (Early Bird, Intermediate, Night Owl).
- **Sleep Cycle Calculator**: Automatically calculates optimal bedtimes and sleep cycles based on 90-minute ultradian rhythms.
- **Cognitive Time-Blocking**: Categorize tasks by cognitive intensity (Deep Work, Shallow Work, Rest, Physical Movement) with real-time total duration and burnout risk estimation.
- **Local Data Persistence**: Saves tasks locally in your browser via `localStorage` with JSON export and import backup capabilities.

## Local Run Instructions
1. Clone or download the repository files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, package managers, or server connections are required.

## Tech Stack
- Vanilla HTML5, CSS3, and JavaScript (ES6+)
- HTML5 Canvas API for real-time circadian wave rendering
- LocalStorage API for secure offline persistence
