# AuraVault

AuraVault is a privacy-first cybersecurity utility designed to inspect password resilience, calculate cryptographic entropy, simulate offline brute-force crack times across modern hardware tiers, and generate high-entropy passphrases entirely client-side.

## Features

- **Real-Time Entropy Calculation:** Computes true combinatorial and Shannon entropy in bits based on character sets and length.
- **Hardware Brute-Force Estimations:** Instantly projects time-to-crack across Desktop CPUs, Gaming GPU rigs, Cloud clusters, and State-level hardware.
- **NIST & Pattern Diagnostics:** Evaluates NIST length recommendations, keyboard walks, repeating patterns, and dictionary weaknesses.
- **Secure Generator:** Built-in Diceware passphrase generator and random alphanumeric/symbol generator utilizing window.crypto.
- **100% Offline & Private:** Zero network requests or telemetry. All processing happens locally in your browser.

## Local Run Instructions

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.

## Static Project Notice

This is a pure static front-end project built with vanilla HTML5, CSS3, and modern JavaScript.
