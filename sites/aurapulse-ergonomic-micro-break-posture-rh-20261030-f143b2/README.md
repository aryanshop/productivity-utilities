# AuraPulse: Ergonomic Micro-Break & Posture Rhythm Architect

AuraPulse is a precision workspace wellness and micro-break rhythm planner designed for desk workers, programmers, and remote professionals. It blends proven time-blocking techniques (Pomodoro/Ultradian rhythms) with somatic desk stretches, posture reminders, and eye-strain prevention guidance.

## Features

- **Precision Interval Timer**: Switch seamlessly between Deep Focus, Micro Breaks, and Desk Stretch sessions.
- **Visual Progress Ring**: Smooth SVG circular progress indicator reflecting session countdown.
- **Somatic & Ergonomic Protocols**: Contextual workspace tips and a dedicated Desk Movement Library (neck release, 20-20-20 eye rule, wrist mobility, thoracic rotation).
- **Web Audio API Chimes**: Gentle, synthesizer-generated ambient audio alerts upon session completion without external audio files.
- **Streak & Session Tracker**: LocalStorage-backed daily productivity logs, focus minutes counter, and active streak monitoring.
- **Privacy-First**: Zero external trackers, cookies, or remote server calls. All data stays locally in your browser.

## Local Run Instructions

1. Download or clone the repository.
2. Open `index.html` directly in any modern web browser.

## Technology Stack

- Pure vanilla HTML5, CSS3, and JavaScript (ES6+).
- No frameworks, build tools, or external package dependencies.
