# AuraDrift: Tire Slip Angle & Vehicle Cornering Physics Lab

AuraDrift is a precision vehicle dynamics and cornering physics simulation workbench designed for automotive engineers, sim racers, motorsport enthusiasts, and physics students.

## Features
- **Real-Time Physics Calculations**: Computes lateral acceleration (g-force), dynamic axle load distribution, front and rear tire slip angles, and understeer/oversteer gradients.
- **Interactive Visualizer**: Top-down HTML5 Canvas trajectory simulator showing tire slip angles and vehicle rotation response.
- **Vehicle Presets**: Instantly switch between Lightweight Sportscars, Family Sedans, Formula Track Cars, and Heavy SUVs.
- **Local Persistence**: Save and load custom setups directly in browser local storage.

## Local Run Instructions
1. Download or clone all repository files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` in any modern web browser.
3. No server setup or external dependencies are required.

## Technology Stack
- Vanilla HTML5, CSS3, and ES6 JavaScript
- HTML5 Canvas 2D Context
- Fully client-side, privacy-focused offline utility.
