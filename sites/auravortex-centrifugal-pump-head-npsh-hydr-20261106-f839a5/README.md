# AuraVortex: Centrifugal Pump Head & NPSH Hydraulic Lab

AuraVortex is a precision fluid dynamics and centrifugal pump hydraulic workbench designed for mechanical engineers, plumbers, aquaculturists, and fluid systems hobbyists.

## Features
- **Fluid Property Profiles:** Supports water at varying temperatures, 30% ethylene glycol, and light hydraulic oil with accurate density, viscosity, and vapor pressure values.
- **Darcy-Weisbach Friction Loss:** Calculates major and minor pipe friction losses across various materials (PVC, copper, steel, cast iron).
- **NPSH Cavitation Analysis:** Evaluates Net Positive Suction Head Available (NPSHa) against vapor pressure limits with real-time cavitation safety alerts.
- **Interactive HTML5 Canvas System Curve:** Renders quadratic system resistance curves intersecting simulated centrifugal pump head curves.
- **Unit System Conversion:** Instantly toggle between US Customary (GPM, ft, psi) and Metric (L/min, m, kPa).
- **Report Export:** Export complete hydraulic calculation summaries as local JSON backup files.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Adjust flow rates, pipe diameters, and elevation lifts to simulate pump performance instantly.

## Built With
- Vanilla HTML5, CSS3, and JavaScript.
- 100% Client-side execution with zero external network requests or tracking.
