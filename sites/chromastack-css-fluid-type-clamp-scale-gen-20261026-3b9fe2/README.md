# ChromaStack: CSS Fluid Type & Clamp Scale Generator

ChromaStack is a professional, privacy-first developer utility designed to calculate and preview CSS fluid typography using mathematical `clamp()` formulas and modular scales.

## Features

- **Fluid Clamp Calculator**: Instantly computes precise `clamp()` expressions combining viewport scaling (`vw`) and base font sizing (`rem`).
- **Modular Scale Ratios**: Choose from standard typographic ratios including Minor Third, Major Third, Perfect Fourth, Golden Ratio, and more.
- **Live Typography Preview**: Test your fluid scale in real-time across headings, body copy, and captions on a simulated preview canvas.
- **One-Click CSS Export**: Copy production-ready CSS custom properties straight to your clipboard.
- **Theme Toggle**: Switch between dark and light workspace themes.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, package managers, or server setups are required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript.
- 100% client-side execution with zero external network requests or tracking.
