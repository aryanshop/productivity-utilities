# AuraForge: Task Prioritization & Time-Blocking Matrix

## Purpose
AuraForge is a local-first productivity laboratory designed to help professionals, makers, and students balance high-level task prioritization with rigorous daily time-blocking.

## Features
- **Eisenhower Priority Matrix**: Categorize tasks into Urgent/Important quadrants to focus on what truly moves the needle.
- **Interactive Time-Blocking Schedule**: Map your day from 08:00 to 18:00 with color-coded categories (Deep Work, Meetings, Admin, Breaks).
- **Real-Time Productivity Analytics**: Track total tasks, completion rates, and visual time distribution breakdowns.
- **Local-First & Private**: All data is securely stored in your browser's local storage with full JSON export/import backup capabilities.

## Local Run Instructions
1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser.
3. Enjoy a fully offline, private productivity studio.

## Technology Stack
- Vanilla HTML5, CSS3, and JavaScript (ES6+)
- Zero external dependencies or network requests.
