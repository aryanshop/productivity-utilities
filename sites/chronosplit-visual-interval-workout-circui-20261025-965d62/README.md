# ChronoSplit: Visual Interval & Workout Circuit Architect

ChronoSplit is a precision interval timer, circuit training architect, and productivity stopwatch web application. Designed for HIIT sessions, Tabata, yoga sequences, mobility flows, and deep-work pomodoro sprints.

## Features
- **Dynamic Circuit Blueprinting**: Create, reorder, and customize multi-phase intervals (Work, Rest, Warmup, Cool-down).
- **Preset Templates**: Instant loading for Tabata Standard, HIIT Power, Focus Sprints, and Mobility Flows.
- **High-Visibility Fullscreen Stopwatch**: Smooth SVG progress rings, color-coded phase badges, and clear countdown digits.
- **Web Audio API Cues**: Clean synthetic chime beeps for countdown ticks and round completions without external audio files.
- **Circuit Analytics**: Real-time calculation of total workout duration, interval counts, and Work/Rest ratios.
- **LocalStorage Persistence**: Save custom circuits and restore them instantly.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No server or build setup required. Completely static and self-contained.

## Privacy & Security
- Zero external scripts, fonts, or tracking.
- All data remains locally in your browser memory.
