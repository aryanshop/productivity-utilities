# StellarBake: Precision Baker's Lab & Formula Scaler

StellarBake is a professional-grade browser utility and calculation workbench for artisan bakers, pastry chefs, and home bread enthusiasts. It simplifies formulating, scaling, and managing dough recipes using the industry-standard Baker's Percentage method.

## Key Features

- **Baker's Percentage Engine**: Instantly scales ingredient quantities (flour, water, levain, salt, butter, sugar) relative to total flour weight.
- **Multi-Unit Support**: Seamlessly toggle between Grams (g), Ounces (oz), and Pounds & Ounces (lb/oz).
- **Water Temperature Wizard**: Calculates exact water temperatures required to hit target Desired Dough Temperatures (DDT), factoring in room temperature, flour temperature, and mixer friction factor.
- **Classic Presets Library**: Quickly load tried-and-true presets like Artisan Sourdough Boule, Traditional Baguette, Rich Brioche, and Neapolitan Pizza Dough.
- **Formula Library**: Save your custom recipes to browser LocalStorage, export formulas as JSON backups, or generate clean, print-friendly recipe cards.

## Local Run Instructions

1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No installation, build tools, or network connections required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- Zero external dependencies, tracking scripts, or external fonts.
