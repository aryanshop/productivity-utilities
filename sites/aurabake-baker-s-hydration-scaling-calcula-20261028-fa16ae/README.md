# AuraBake: Baker's Hydration & Scaling Calculator

AuraBake is a professional baker's percentage calculation and recipe scaling studio designed for artisan bread makers, pastry chefs, and home bakers.

## Features

- **Baker's Percentages**: Automatically calculates flour blends, total hydration %, and ingredient ratios relative to total flour (100%).
- **Dynamic Recipe Scaling**: Scale recipes instantly by setting a target dough weight (grams) or applying a direct scale multiplier.
- **Customizable Ingredient Categories**: Add, edit, or remove flours, liquids, levain, salt, butter, and inclusions.
- **Visual Composition Breakdown**: Live interactive horizontal proportion bar showing ingredient mass distribution.
- **Formula Summary & Export**: Clean weight sheet table with exact gram measurements and one-click formula text export.
- **Local-First Recipe Vault**: Save formulas directly to browser `localStorage` and reload them instantly.
- **Artisan Presets**: Quick-load templates for Country Sourdough, French Baguette, Rich Brioche, and Neapolitan Pizza Dough.

## Local Run Instructions

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, external servers, or package installations required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- Zero external dependencies or external requests.
