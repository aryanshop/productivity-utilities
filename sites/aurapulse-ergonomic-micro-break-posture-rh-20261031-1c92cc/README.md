# AuraPulse: Ergonomic Micro-Break & Posture Rhythm Architect

AuraPulse is a precision workspace wellness and micro-break rhythm planner designed for desk workers, programmers, and remote professionals. It blends deep focus timing with targeted ergonomic stretches, somatic movement prompts, and custom audio chimes.

## Features
- **Customizable Work-Rest Rhythms**: Switch seamlessly between Deep Work, Micro-Breaks, and Long Resets with configurable time durations.
- **Visual SVG Progress Ring**: Clean, modern circular countdown indicator providing instantaneous visual feedback.
- **Ergonomic Stretch & Posture Prescriptions**: Automatically rotates through expert desk stretches, carpal relief, and eye strain exercises between sessions.
- **Web Audio API Chimes**: Built-in harmonic synthesizer providing gentle audio notifications without external sound files.
- **Local Streak & Session Logging**: Tracks completed focus sessions, total accumulated focus minutes, and daily movement streaks stored locally via `localStorage`.
- **Privacy First**: 100% client-side with zero external network dependencies, trackers, or cookies.

## Local Run Instructions
1. Download or clone the repository.
2. Open `index.html` directly in any modern web browser.
3. Click **Start Session** or press `Spacebar` to begin your focus cadence.
