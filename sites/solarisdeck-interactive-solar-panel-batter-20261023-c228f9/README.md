# SolarisDeck: Solar Panel & Battery Storage ROI Planner

SolarisDeck is a privacy-first, interactive solar photovoltaic (PV) generation and battery storage financial payback calculator. It is designed for homeowners and small businesses exploring clean energy investments.

## Features

- **Interactive System Configuration**: Fine-tune average monthly electricity bills, utility rates, solar array size (kW), battery storage capacity (kWh), peak sun hours, and tax incentives.
- **Real-Time Financial Metrics**: Instant calculation of annual bill savings, simple payback period, 25-year net profit, and cumulative carbon offsets.
- **Visual Cash Flow Projection**: A responsive HTML5 canvas chart rendering 25-year cumulative cash flow curves factoring in electricity cost inflation.
- **Energy Balance Breakdown**: Visualizes daily generation, household load, battery self-consumption, and grid export ratios.
- **Scenario Comparison Ledger**: Save multiple system configurations locally and compare their economic viability instantly.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. No build tools, package managers, or server connections are required.

## Technology Stack

- Vanilla HTML5 & CSS3 (Custom responsive Grid & Flexbox layout)
- Vanilla JavaScript (ES6+, HTML5 Canvas API, LocalStorage)
- 100% Client-Side & Privacy-First (No external requests or tracking)
