# AeroStitch: Parametric Parachute & Aerodynamic Decelerator Designer

AeroStitch is a professional-grade parametric calculator and design workbench built for rocketeers, makers, and aerospace enthusiasts who need to design reliable parachutes and aerodynamic decelerators.

## Features
- **Physics-Based Calculations**: Computes terminal velocity, nominal diameter, surface area, and touchdown kinetic energy based on payload mass, descent rate, and altitude-adjusted air density.
- **Canopy Geometry Modeling**: Supports Hemispherical, Cruciform, Annular, and Flat Circular canopies with customizable gore counts and spill hole ratios.
- **Interactive SVG Blueprint**: Renders precise gore panel templates with seam allowances and scaling dimensions.
- **Material Cut List & Rigging Specs**: Generates fabric yardage requirements, suspension line breaking strength ratings incorporating safety factors, and total cordage estimates.
- **Export & Summary**: One-click blueprint summary generation with copy-to-clipboard functionality.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, external dependencies, or network connections are required.

## Technology Stack
- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+)
- Responsive CSS Grid & Flexbox layout
- Dynamic SVG rendering for real-time visual blueprints

## Static Project
This is a fully self-contained client-side static web application with no server-side storage or tracking.
