# AuraSlate: Markdown Kanban & Focus Sprint Board

AuraSlate is a privacy-first, local-first Kanban task management workbench and focus sprint timer designed for developers, writers, and focused creators.

## Features
- **Kanban Board**: Drag and drop tasks seamlessly across Backlog, To Do, In Progress, and Done columns.
- **Markdown Notes**: Write rich notes with headers, bold text, bullet points, and interactive task checklists, complete with a live preview pane.
- **Focus Sprint Timer**: Built-in Pomodoro and deep work timer with custom preset intervals (15m, 25m, 50m) to maintain flow state.
- **Search & Filter**: Filter instantly by keyword search (including hashtags like `#bug`) or priority level (High, Medium, Low).
- **Local Persistence & Backup**: All data is securely stored in your browser's `localStorage` with full JSON export and import capabilities.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, package managers, or server configuration required. Completely static and offline-ready.

## Tech Stack
- Vanilla HTML5, CSS3, and JavaScript (ES6+).
- Zero external dependencies or network requests.
