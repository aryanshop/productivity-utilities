# AuraBrew: Specialty Coffee Extraction & Ratio Lab

AuraBrew is a precision specialty coffee brewing calculator, extraction analyzer, and brew timer workbench designed for coffee aficionados, baristas, and home brewers.

## Features

1. **Extraction & Ratio Calculator**:
   - Instantly computes exact water weight based on coffee dose and brew ratio.
   - Estimates extraction yield and TDS (Total Dissolved Solids) based on grind profile and method defaults.
2. **Interactive Pour-Over Schedule & Timer**:
   - Generates step-by-step timed pouring blueprints for Hario V60, Chemex, French Press, and AeroPress.
   - Interactive SVG progress ring timer with Web Audio API chime cues at key pour intervals.
3. **Bean Stash & Tasting Ledger**:
   - Log your favorite specialty roasts, processing methods, and ratings.
   - Local storage persistence with one-click JSON backup and restore.

## Running Locally

Simply open `index.html` in any modern web browser. No build tools, package managers, or server configuration required.

## Technical Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+)
- Zero external dependencies or network requests
- Fully responsive and accessible design
