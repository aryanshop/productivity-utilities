# StellarShift: Interplanetary Time & Gravity Offset Calculator

StellarShift is a polished, client-side productivity-utility and scientific simulation tool designed for space mission planners, science fiction writers, and astronomy enthusiasts.

## Features
- **Relativistic & Gravitational Time Dilation**: Computes precise clock drift between Earth and destination planetary bodies (Moon, Mars, Europa, Titan) based on general relativity (gravitational potential).
- **Kinematic Starship Mode**: Simulates special relativity time dilation for vessels traveling at fractional speeds of light using Lorentz factor calculations.
- **Interplanetary Synchronization Matrix**: Visualizes 24-hour schedules and overlapping working windows across different celestial day lengths (Sols).
- **Mission Briefing Export**: Instantly export a clean text summary of your mission telemetry and relativistic calculations.
- **100% Client-Side**: Built with vanilla HTML5, CSS3, and modern JavaScript. No external libraries, network requests, or data tracking.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser.
3. Adjust mission parameters, select a habitat or starship speed, and click **Compute Relativistic Shift**.

## Built As
A standalone, static web utility adhering strictly to responsive design and accessibility standards.
