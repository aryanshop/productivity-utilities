# AuraRoot: Permaculture Companion Planting & Guild Layout Laboratory

AuraRoot is a precision permaculture garden design and companion planting workbench built for homesteaders, urban gardeners, and landscape designers. It enables users to design multi-layer food forest guilds, analyze ecological synergy, check nitrogen-fixing and pest-deterring compatibility, and export/import their garden layouts locally.

## Features

- **Interactive Guild Canvas:** Place trees, shrubs, dynamic accumulators, nitrogen fixers, and ground covers onto a customizable grid plot.
- **Plant Catalog & Stratification:** Filter plants across 7-layer food forest categories (Canopy, Understory, Shrub, Herbaceous, Rhizosphere, Ground Cover).
- **Synergy & Health Scoring:** Real-time calculation of ecological resilience, nitrogen cycling, and pest prevention.
- **Permaculture Audit Report:** Automated recommendations for companion planting improvements and soil health optimization.
- **Local-First JSON Backup:** Save, export, and import your complete guild configurations securely in your browser without any external network requests or tracking.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. That's it! No build tools, package managers, or server connections required.

## Static Project Note
This project is entirely static and runs client-side with zero telemetry or data collection.
