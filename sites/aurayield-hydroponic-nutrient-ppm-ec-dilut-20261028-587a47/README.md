# AuraYield: Hydroponic Nutrient PPM & EC Dilution Lab

## Purpose
AuraYield is a precision hydroponic nutrient solution calculator and EC/PPM mixer workbench designed for indoor growers, urban farmers, greenhouse operators, and botany enthusiasts. It eliminates guesswork by calculating precise stock concentrate dosages required to hit exact Electrical Conductivity (EC) and Parts Per Million (PPM) targets for different plant growth stages.

## Features
- **Reservoir Configuration:** Supports both US Gallons and Liters with adjustable total volumes.
- **Growth Stage Presets:** Instantly load scientifically balanced EC targets for Seedling, Vegetative, Blooming, and Fruiting stages (or Tomatoes, Leafy Greens, and Strawberries).
- **Stock Nutrient Inventory:** Manage 3-part or custom nutrient formulas with real-time ML-per-gallon dosing calculations.
- **TDS Conversion Scales:** Toggle between 500 Scale (NaCl) and 700 Scale (442) PPM readings.
- **EC Contribution Visualizer:** Interactive HTML5 Canvas breakdown chart displaying proportional EC contributions from source water and individual nutrient concentrates.
- **Evaporation Top-Off Calculator:** Compute pure water top-off volumes when water levels and salt concentrations rise due to plant transpiration.
- **Recipe Export:** One-click recipe formatting for saving, printing, or sharing your custom fertilizer schedule.

## Local Run Instructions
1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No installation, build tools, or internet connection required (100% client-side vanilla JavaScript).

## Technology Stack
- **HTML5:** Semantic layout with responsive CSS Grid & Flexbox.
- **CSS3:** Custom properties (CSS variables), modern dark-theme dashboard design.
- **JavaScript (ES6+):** Pure vanilla implementation with real-time recalculation and HTML5 Canvas rendering.
