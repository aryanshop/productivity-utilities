# ZenFlow Micro-Habit Tracker & Ritual Timer

ZenFlow is a polished, lightweight productivity and mindfulness web application designed to help you organize daily ritual sequences, track tiny micro-habits, and practice mindful reflection.

## Features

1. **Ritual Timer**: Chain together custom timed steps (e.g., breathwork, hydration, goal review). Features an animated visual breath halo, countdown clock, and step sequencing controls.
2. **Micro-Habit Tracker**: Build consistency through tiny habits with persistent streak counters stored securely in your browser.
3. **Reflection Journal**: Daily thought prompts to help clear mental clutter with local draft autosaving.

## Local Run Instructions

1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enjoy a fully functional, offline-capable static application!

## Technical Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+)
- LocalStorage for client-side persistence
- Zero external dependencies, build steps, or network requests.
