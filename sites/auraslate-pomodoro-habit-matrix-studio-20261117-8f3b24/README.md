# AuraSlate: Pomodoro & Habit Matrix Studio

AuraSlate is a privacy-first, local-first productivity studio designed for makers, students, and professionals who value absolute control over their workflow data. It combines three essential productivity systems into one polished, responsive web application:

1. **Focus Timer**: A customizable Pomodoro timer with mode switching (Pomodoro, Short Break, Long Break), SVG circular progress animation, and synthesized Web Audio API chime alerts.
2. **Eisenhower Priority Matrix**: An interactive task board split into four strategic quadrants (Do, Schedule, Delegate, Eliminate) with completion status tracking.
3. **Daily Habit Streaks**: A weekly habit tracker featuring real-time streak calculation and persistent local storage.

## Features

- **100% Privacy First**: All tasks, habits, and focus metrics are stored securely in your browser's `localStorage` with zero trackers, cookies, or external server calls.
- **JSON Backup & Restore**: Easily export your entire workspace to a JSON file or restore from a previous backup.
- **Polished Responsive Design**: Built with clean vanilla CSS, modern dark mode aesthetics, and smooth transitions.
- **Audio Feedback**: Built-in Web Audio API tone generator signals session transitions without external media files.

## Local Run Instructions

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enjoy a distraction-free, high-performance productivity studio!
