# ZenithCanvas: Visual Eisenhower & Time-Blocking Matrix Studio

ZenithCanvas is a privacy-first productivity utility designed to help professionals, students, and creators prioritize tasks efficiently using the classic Eisenhower Matrix and structure their days with a 24-hour time-blocking schedule grid.

## Features

- **Eisenhower Priority Matrix**: Organize tasks into four strategic quadrants (Do First, Schedule, Delegate, Eliminate) with real-time counters.
- **Daily Time-Blocking Grid**: Allocate your tasks into hourly time slots (06:00 to 22:00) for disciplined schedule execution.
- **Analytics & Scorecard**: Interactive SVG pie chart breakdown of your quadrant distribution and personalized productivity feedback.
- **Local Persistence**: All data is securely stored locally in your browser (`localStorage`).
- **JSON Backup & Restore**: Export your workflow data to a JSON file or import backups instantly.

## Local Run Instructions

This is a purely static front-end application with no external dependencies or build steps required.

1. Download or clone the project files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` directly in any modern web browser.

## Tech Stack

- HTML5, CSS3 (CSS Variables, Flexbox, Grid), and vanilla ES6+ JavaScript.
