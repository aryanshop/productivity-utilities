# AuraStride: Running Biomechanics & Cadence Metronome Lab

AuraStride is a precision running biomechanics workbench and audio-visual metronome designed for runners, coaches, and endurance athletes seeking to optimize stride rate and efficiency.

## Features
- **Target Cadence & Pace Calculations**: Computes optimal stride length, estimated Ground Contact Time (GCT), vertical oscillation, and calorie burn rates.
- **Web Audio API Metronome**: Generates precise audio clicks synchronized to target steps-per-minute (SPM) with accent beats.
- **Real-Time Visualizer**: Dynamic HTML5 canvas waveform simulating running stride frequency.
- **Local Session Ledger**: Save custom biomechanical configurations securely in browser localStorage.

## Local Run Instructions
1. Download or clone repository files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` directly in any modern web browser.

## Static Project Note
This application is 100% client-side with no external dependencies or server communication.
