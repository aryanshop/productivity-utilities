# ZenithType: Micro-Typography Rhythm & Vertical Rhythm Grid Calculator

ZenithType is a professional-grade typographic rhythm workbench and vertical baseline grid calculator designed for web designers, developers, and typography enthusiasts. It computes mathematically harmonious modular type scales, snaps line heights and vertical margins to a customizable baseline grid unit, and generates production-ready CSS custom properties with fluid `clamp()` formulas.

## Key Features
- **Modular Scale & Base Controls**: Configure base font sizes, modular ratios (Minor Second, Major Third, Perfect Fourth, Golden Ratio, etc.), and line heights.
- **Vertical Baseline Grid Overlay**: Toggle a real-time background grid on a simulated editorial preview canvas to instantly inspect vertical rhythm alignment.
- **Fluid Clamp() Generation**: Automatically computes viewport-scaling typography formulas for responsive web layouts.
- **Editorial Preview Canvas**: Test typography live across simulated viewport widths (Mobile, Tablet, Desktop, Wide) with selectable preview font families.
- **Type Scale Matrix**: Inspect exact pixel and rem sizes for every hierarchy level.
- **CSS Export**: One-click code generation and clipboard copy for immediate integration into CSS stylesheets.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, package managers, or external network requests required.

## Static Project Notice
This is a fully self-contained static client-side web utility built with vanilla HTML5, CSS3, and JavaScript.
