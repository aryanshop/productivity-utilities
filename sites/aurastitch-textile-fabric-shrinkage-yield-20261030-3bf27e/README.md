# AuraStitch: Textile Fabric Shrinkage & Yield Estimator

AuraStitch is a precision sewing, tailoring, and textile yardage calculator designed for garment makers, quilters, and DIY crafters. It computes accurate fabric requirements, post-wash shrinkage allowances, pattern matching waste percentages, and grainline yield optimization.

## Features

- **Pre-Treatment Shrinkage Calculation:** Automatically adjusts pattern cut dimensions based on warp (length) and weft (width) post-wash shrinkage rates.
- **Dynamic Pattern Piece Manager:** Add, edit, or remove custom garment pieces with adjustable quantities and dimensions.
- **Simulated Bolt Layout Blueprint:** Interactive SVG visualizer mapping grainlines and pattern blocks across standard fabric bolt widths.
- **Cost & Waste Estimator:** Calculates total yardage, total cost, average cost per panel, and waste percentages.
- **Exportable Cut Sheet:** Instantly download a comprehensive TXT report of your cut specifications and project parameters.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No installation, build steps, or server required (100% static client-side application).

## Technologies Used

- Vanilla HTML5, CSS3, and JavaScript (ES6+)
- Responsive CSS Grid and Flexbox layout
- Interactive SVG Canvas rendering
- Local Blob generation for cut sheet file export
