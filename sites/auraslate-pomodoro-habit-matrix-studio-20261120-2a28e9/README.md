# AuraSlate: Pomodoro & Habit Matrix Studio

AuraSlate is a privacy-first, local-first productivity studio combining a customized Pomodoro focus timer with an Eisenhower Priority Matrix and daily habit tracker.

## Features
- **Focus Timer**: Configurable Pomodoro (25m), Short Break (5m), and Long Break (15m) timer with Web Audio API celebratory chime and interactive circular progress ring.
- **Eisenhower Priority Matrix**: Organize tasks across 4 quadrants (Urgent & Important, Not Urgent & Important, Urgent & Not Important, Not Urgent & Not Important).
- **Daily Habit Tracker**: Track consistency across 7 weekly days with automatic streak counters.
- **Local-First & Private**: All data is securely stored in your browser's `localStorage`. Export and import JSON backups anytime or reset your workspace securely.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enjoy a fully offline, lightning-fast productivity experience!

## Static Project Statement
This project is built with vanilla HTML5, CSS3, and modern JavaScript without relying on any frameworks, external build steps, tracking cookies, or network requests.
