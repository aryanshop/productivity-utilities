# AuraPinch: Bonsai Potting Soil & Drainage Ratio Laboratory

## Purpose
AuraPinch is a precision horticultural utility designed for bonsai artists, container gardeners, and plant enthusiasts who want to formulate optimal soil substrates. Proper bonsai soil requires a delicate balance of water retention, nutrient exchange capacity (CEC), and extreme aeration to prevent root rot.

## Features
- **Target Volume Calculation:** Compute exact volumetric requirements in Quarts, Liters, or Gallons for custom pot sizes.
- **Interactive Ratio Sliders:** Fine-tune proportions of Akadama, Pumice, Lava Rock, and Organic Compost with intuitive smart normalization.
- **Preset Profiles:** Instantly load recommended professional mixes for Conifers, Deciduous trees, and Tropical bonsai.
- **Laboratory Analysis:** Real-time metrics for Aeration Index, Water Retention capacity, and estimated dry pot weight.
- **Pot Layering Blueprint:** Visual guide for structuring coarse drainage layers, mid root matrices, and top-dressings.
- **Local Recipe Vault:** Save, review, and manage custom soil recipes securely using browser `localStorage`.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser.
3. No server setup, compilation steps, or external dependencies required.

## Technical Note
This project is entirely client-side, privacy-first, and built with vanilla HTML5, CSS3, and modern JavaScript.
