# AuraVoxel: 3D Isometric Pixel Art Grid & CSS Code Synthesizer

AuraVoxel is a precision 3D isometric pixel art designer and pure CSS box-shadow code generator built for web developers, retro game artists, and UI designers. Create stunning isometric voxel icons and scenes directly on an interactive canvas, manage height elevations, and instantly synthesize multi-layer box-shadow CSS code.

## Features

- **Interactive Isometric Canvas**: Full HTML5 Canvas isometric rendering with smooth panning, zooming, and grid adjustment (8x8 up to 24x24).
- **Precision Toolbox**: Draw, Erase, Eyedropper (Color Picker), and Bucket Flood Fill tools.
- **Elevation Z-Index Layers**: Build multi-story 3D structures with layer height controls up to Z-15.
- **Curated & Custom Palettes**: Switch instantly between Cyberpunk, Pastel, GameBoy, and Monolith color palettes or pick custom RGB colors.
- **CSS Box-Shadow Synthesizer**: Automatically generates clean, production-ready multi-layer CSS box-shadow code for rendering isometric art with single HTML elements.
- **Local Persistence & Export**: Automatically saves workspace sessions locally via localStorage and supports full JSON backups.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, package managers, or server setups are required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- Zero external dependencies, libraries, or network requests.
