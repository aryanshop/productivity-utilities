# AuraVelo: Bicycle Gear Ratio & Drivetrain Lab

AuraVelo is a professional-grade, offline-first bicycle drivetrain calculator and cadence speed analysis workbench. Designed for cyclists, bike mechanics, and commuters.

## Features
- **Comprehensive Drivetrain Customization**: Input custom front chainring sets and rear cassette cog arrangements.
- **Wheel & Tire Calibration**: Select from standard road, gravel, MTB, and BMX ISO tire sizes for precise circumference calculations.
- **Cadence Speed Matrix**: Real-time evaluation of gear inches, meters of development, gear range spread percentages, and speeds across variable pedal cadences.
- **Interactive Canvas Visualization**: Speed vs. Cadence curves highlighting climbing and sprinting gear thresholds.
- **CSV Export**: One-click data export for offline analysis.

## Local Run Instructions
Simply open `index.html` in any modern web browser. No build tools or server dependencies required.

## Technology Stack
- Vanilla HTML5
- CSS3 (Variables, Grid, Responsive Flexbox)
- Modern Vanilla JavaScript (Canvas API, DOM manipulation)
