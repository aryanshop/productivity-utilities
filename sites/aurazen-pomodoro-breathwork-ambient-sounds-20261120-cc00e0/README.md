# AuraZen: Pomodoro Breathwork & Ambient Soundscape Laboratory

AuraZen is a privacy-first, local-first productivity studio designed for deep cognitive focus, guided breathwork cadences, and immersive ambient audio generation. 

## Features

- **Pomodoro Focus Engine**: Customizable work, short break, and long break intervals with animated circular SVG progress rings, session trackers, and audio chime alerts.
- **Breathwork Cadence Trainer**: Guided somatic breathing visualizer supporting Box Breathing (4-4-4-4), Relaxing Breath (4-7-8), Energizing Breath (6-2-6-2), and Equal Calm patterns.
- **Ambient Soundscape Laboratory**: Fully synthesized Web Audio API sound generators featuring White Noise, Pink Noise (Rain simulation), Brown Noise (Deep Ocean), and 432Hz / 528Hz Solfeggio harmonic drone tones with zero external audio files.
- **Session Analytics & Daily Streak Tracker**: Automatically records completed focus intervals, total focus minutes, and maintains active day streaks with local storage persistence.
- **100% Privacy-First**: No servers, no tracking, no cookies, and zero network calls.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. Enjoy focus, breathing, and ambient sound generation offline!
