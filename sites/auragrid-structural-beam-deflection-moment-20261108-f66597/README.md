# AuraGrid: Structural Beam Deflection & Moment Laboratory

AuraGrid is a professional client-side structural engineering and mechanical load calculator built for engineers, architects, students, and DIY builders. It computes exact beam deflections, bending moments, shear forces, and safety factor margins across diverse support conditions and cross-sectional geometries.

## Features

- **Support Configurations**: Simply Supported, Cantilever (Fixed-Free), and Fixed-Fixed.
- **Cross-Section Profiles**: Rectangular, I-Beam, Hollow Tube, and Circular profiles with fully adjustable dimensions.
- **Material Library**: Presets for Structural Steel (A36), Aluminum (6061-T6), Douglas Fir Timber, and Reinforced Concrete with custom Elastic Modulus and Yield Stress inputs.
- **Load Types**: Uniform Distributed Load (UDL), Center Point Load, and Arbitrary Point Loads.
- **Interactive Visualizer**: HTML5 Canvas rendering engine featuring real-time deformation curves, Bending Moment (M) diagrams, and Shear Force (V) diagrams.
- **Session Presets**: Save and inspect custom beam configurations locally.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No server setup, build tools, or external dependencies are required. All calculations run locally in the browser.

## Technology Stack

- Pure HTML5, CSS3, and Vanilla JavaScript (ES6+).
- Responsive CSS Grid and Flexbox layout.
- HTML5 Canvas 2D Context for structural diagram plotting.

## Disclaimer

AuraGrid is designed as an educational and preliminary estimation workbench. Always verify critical load calculations and engineering specifications with a licensed structural engineer before construction.
