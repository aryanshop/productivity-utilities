# AuraPulse: Ergonomic Micro-Break & Posture Rhythm Architect

AuraPulse is a precision workspace wellness and micro-break rhythm planner designed for desk workers, programmers, and remote professionals. It combines customizable focus intervals (Pomodoro, Ultradian rhythms) with somatic desk stretches, eye-strain relief exercises, posture checklists, and Web Audio API chimes.

## Features

- **Focus & Rhythm Timer**: Animated SVG progress ring timer with configurable work and break intervals, instant preset toggles, and session state tracking.
- **Somatic Stretch Library**: Filterable database of ergonomic stretches, neck/shoulder mobility drills, wrist tendon relief, and 20-20-20 eye strain exercises.
- **Web Audio API Chimes**: Soft synthesized audio chimes to gently notify when focus blocks or breaks conclude.
- **Movement & Rhythm Analytics**: Local streak counter, total focus minutes, session history log table, and data export/import capabilities.
- **Posture & Ergonomic Guidelines**: Built-in workstation checklist to maintain neutral spine alignment and correct monitor height.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, package managers, or server connections required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+)
- Web Audio API for synthetic audio feedback
- HTML5 SVG for circular countdown visualization
- Browser `localStorage` for privacy-first state retention
