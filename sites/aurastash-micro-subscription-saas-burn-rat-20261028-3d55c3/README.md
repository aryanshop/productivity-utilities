# AuraStash: Micro-Subscription & SaaS Burn Rate Auditor

## Purpose
AuraStash is a local-first micro-subscription and SaaS burn rate auditor designed for freelancers, remote professionals, indie hackers, and households. It helps uncover recurring software and service expenses, compute monthly and annual commitments, visualize category breakdowns, and simulate the exact financial impact of cancelling unused subscriptions.

## Features
- **Live Financial Dashboard**: Instantly tracks Monthly Burn, Annual Commitment, and Daily equivalent cost.
- **Flexible Billing Cycles**: Supports monthly, annual, weekly, and quarterly billing cycles with automatic normalization.
- **Category Breakdown Bars**: Real-time visual progress representation of spending distribution across Developer Tools, Cloud & Hosting, Productivity, Entertainment, and more.
- **Trim Simulator**: Interactive toggle checkboxes to simulate savings instantly if you decide to prune specific subscriptions.
- **Search & Filter**: Quickly locate specific services across large software stacks.
- **Local Data Persistence & Backup**: Saved safely to browser `localStorage`. Includes one-click JSON export and import capabilities.

## Running Locally
1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.

## Static Project Notice
This project is entirely client-side, built with vanilla HTML5, CSS3, and JavaScript. No external build steps, frameworks, or network requests required.
