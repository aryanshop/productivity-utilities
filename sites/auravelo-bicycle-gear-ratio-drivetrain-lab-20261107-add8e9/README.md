# AuraVelo: Bicycle Gear Ratio & Drivetrain Lab

AuraVelo is a professional precision bicycle gear ratio, cadence speed, and drivetrain calculator designed for cyclists, bike builders, commuters, and mechanics.

## Features

- **Drivetrain Configuration**: Configure front chainring tooth counts and rear cassette cog teeth.
- **Preset Riding Disciplines**: Quick-load setups for Road, Gravel, Mountain Bikes, and Commuters.
- **Wheel & Tire Metrics**: Select standard ISO wheel dimensions or enter custom millimeter circumferences.
- **Cadence & Speed Matrix**: Instantly calculates development ratios, gear inches, and speed in km/h or mph at target cadence.
- **Interactive HTML5 Canvas Chart**: Visualizes gear distribution curves across chainrings and cogs.
- **Responsive & Accessible UI**: Clean dark-theme layout crafted with responsive grid layouts and clean vanilla JavaScript.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, package managers, or server setups required. Fully client-side.
