# AuraFlow: Visual State Machine & Logic Flow Diagramming Studio

AuraFlow is a precision client-side visual state machine and logic flow diagramming studio designed for software architects, systems engineers, and process designers.

## Features
- **Interactive Node Palette**: Drag and drop start states, process states, decision gates, action hooks, and end states onto an infinite canvas.
- **Smart Connecting Tools**: Connect nodes with directional transition lines and labels.
- **Node Inspector**: Configure node titles, trigger payloads, and inspect properties in real-time.
- **Live State Simulation**: Run step-by-step simulations tracing state execution paths with live console logging.
- **Local JSON Backup**: Export and import complete workflow definitions securely with zero server dependencies.

## Local Run Instructions
1. Download or clone all files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser.

*Note: This is a 100% static client-side web application with no external dependencies or server requirements.*
