# AuraWeld: Metal Shielded Arc & MIG Welding Heat Input Laboratory

AuraWeld is a precision welding engineering and metallurgical laboratory built for fabricators, welding inspectors, and metalworking professionals. It calculates arc energy, heat input, cooling rate indicators (t8/5 simulation), and metallurgical advisory guidelines in real-time.

## Features

- **Multi-Process Support**: Configure GMAW (MIG), GTAW (TIG), SMAW (Stick), and FCAW parameters.
- **Shielding Gas & Efficiency Adjustments**: Select shielding gas compositions and thermal efficiency factors (&eta;).
- **Heat Input Calculations**: Instantly computes Arc Energy (kJ/in) and net Heat Input (kJ/in).
- **Interactive HAZ Canvas Visualizer**: Renders dynamic cross-sectional weld profiles and Heat-Affected Zones based on heat input.
- **Metallurgical Advisory**: Warns against hydrogen cracking risks for high carbon equivalent (CE) steels and excessive grain growth.
- **Run Logging & Export**: Save test runs to a local table and export complete audit reports to JSON.

## Local Run Instructions

1. Download or clone all files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser.
3. Fully static and client-side with zero external dependencies or network requests.
