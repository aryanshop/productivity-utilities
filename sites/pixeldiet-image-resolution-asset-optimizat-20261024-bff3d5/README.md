# PixelDiet

PixelDiet is a local-first image asset audit and optimization inspection utility designed for web developers, designers, and content creators. It runs entirely in your browser with zero server uploads.

## Features

- **Drag & Drop Inspection**: Drop multiple PNG, JPEG, WebP, GIF, or SVG files to instantly inspect dimensions, aspect ratios, file sizes, and MIME types.
- **Performance Impact Simulator**: Calculates estimated load times across simulated 4G mobile and broadband network speeds.
- **Responsive Code Generators**: Automatically generates copy-ready HTML `<img srcset>` tags and CSS background rules.
- **Batch Summaries & JSON Export**: Track total storage footprints and export comprehensive asset audit reports.

## Local Run Instructions

1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single directory.
2. Open `index.html` directly in any modern web browser.

## Technical Note

Built with vanilla HTML5, CSS3, and modern JavaScript using the HTML5 File and FileReader APIs. No external dependencies, libraries, or network requests are used.
