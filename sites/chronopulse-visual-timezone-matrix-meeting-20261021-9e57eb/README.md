# ChronoPulse: Visual Timezone Matrix & Meeting Overlap Planner

ChronoPulse is a high-utility, privacy-first productivity tool designed for remote teams, distributed organizations, and global travelers to coordinate schedules without timezone math fatigue.

## Features

- **Interactive 24-Hour Timeline Scrubber:** Scrub effortlessly across hours of the day to instantly preview time changes across all added locations simultaneously.
- **Working Hours Heatmap Matrix:** Visual 24-hour mini bars highlight normal business hours (09:00 - 18:00) versus off-hours for every selected city.
- **Automated Overlap Intelligence:** Instantly calculates common business meeting windows when all participating cities fall within working hours.
- **Dynamic Timezone Management:** Add or remove cities and timezones instantly from a comprehensive global list.
- **Zero External Dependencies:** Completely client-side vanilla JavaScript, HTML5, and CSS3. No external fonts, analytics, tracking, or network requests.

## Local Run Instructions

1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enjoy instant timezone coordination!
