# AuraPulse: Ergonomic Micro-Break & Posture Rhythm Architect

AuraPulse is a privacy-first workspace wellness utility and productivity timer designed to balance deep focus intervals with somatic desk stretches, eye strain prevention routines, and calming Web Audio API ambient soundscapes.

## Features
- **Precision Rhythm Modes:** Switch between standard Pomodoro, 20-20-20 Vision intervals, and fully customizable focus cycles.
- **Interactive SVG Circular Timer:** Smooth progress ring tracking elapsed time and phase transitions.
- **Somatic Stretch & Posture Desk Routine:** Curated ergonomic exercises with descriptions and durations tailored for desk workers.
- **Web Audio API Ambient Soundscapes:** Generate custom offline sound textures (Pink noise, Brown noise, Binaural 40Hz Gamma beats, and Gentle Rain) with adjustable volume control.
- **Local Persistence & Journaling:** Keep track of session streaks, completed focus blocks, micro-breaks, and quick posture journal notes stored securely via browser `localStorage`.
- **100% Client-Side & Privacy-First:** No external tracking, no APIs, no server dependencies.

## Local Run Instructions
1. Download or clone the repository files (`index.html`, `style.css`, `script.js`).
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enjoy focused work sessions and mindful micro-breaks!

## Static Project Notice
This project is built using vanilla HTML5, CSS3, and modern JavaScript with zero external frameworks, build steps, or network requests.
