# FocusPulse: Pomodoro & Cognitive Flow Logger

FocusPulse is an advanced, privacy-first Pomodoro timer and cognitive flow journal designed to help developers, students, and professionals structure deep work sessions and track their productivity energy levels.

## Features

- **Configurable Intervals**: Easily switch between Deep Work (25 min), Short Break (5 min), and Long Break (15 min) modes.
- **Circular SVG Progress Ring**: Smooth real-time visual progress indicator synchronized with the countdown timer.
- **Cognitive Flow Logger**: Log completed tasks, self-assess energy levels (1-5 scale), note distraction counts, and write quick session reflections.
- **Local Storage Persistence**: All your session logs are securely stored in your browser's local storage with zero external tracking or data transmission.
- **Responsive & Accessible**: Clean, modern dark-mode interface optimized for desktop and mobile devices.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, package managers, or server setups required!

## Tech Stack

- **HTML5** (Semantic markup)
- **CSS3** (Custom properties, Flexbox, Grid)
- **Vanilla JavaScript** (ES6+ with clean modular structure)
