# ChronoCaffeine: Biological Half-Life & Sleep Quality Optimizer

ChronoCaffeine is a precision productivity utility and pharmacokinetics calculator designed for professionals, students, and athletes to optimize daily caffeine intake, maintain peak cognitive alertness windows, and protect deep sleep quality.

## Features

- **First-Order Elimination Kinetics**: Calculates continuous blood plasma concentration curves ($C(t) = C_0 \cdot e^{-kt}$) across a 24-hour timeline based on individual metabolic half-life (adjustable from fast 3-hour to slow 9-hour profiles).
- **Quick Beverage Logging**: Pre-configured buttons for espresso, drip coffee, matcha, energy drinks, and black tea, plus custom dose entries.
- **Sleep Hygiene Advisor**: Real-time evaluation of bedtime residual caffeine, automatic calculation of daily caffeine curfew, and projected sleep quality scores.
- **Interactive Canvas Graph**: Responsive high-DPI waveform visualization showing plasma levels, sleep windows, intake markers, and safety thresholds.
- **100% Private & Local-First**: All data is stored securely in browser `localStorage`. No external network requests, analytics, or tracking.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enjoy a fully offline, responsive productivity application.
