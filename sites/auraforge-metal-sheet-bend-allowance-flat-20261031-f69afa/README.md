# AuraForge: Metal Sheet Bend Allowance & Flat Pattern Lab

AuraForge is a precision sheet metal fabrication and design utility built for metalworkers, engineers, and DIY fabricators. It computes exact bend allowances (BA), bend deductions (BD), setback, and flat pattern blank dimensions.

## Features
- **Material Presets**: Quick selection for Aluminum, Mild Steel, Stainless Steel, Copper, and Brass with standard K-factors or custom manual entry.
- **Precision Geometry**: Computes Bend Allowance, Setback, and Bend Deduction instantly based on thickness, inside radius, and bend angle.
- **Interactive Visualizations**: Scale-aware canvas previews of both bent profile schemas and flat pattern blank layouts.
- **Session Logging**: Save and review calculation records directly to local storage for quick shop floor reference.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Completely client-side and static; no server or internet connection required.
