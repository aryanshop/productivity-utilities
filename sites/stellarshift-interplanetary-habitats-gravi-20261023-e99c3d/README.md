# StellarShift: Interplanetary Habitats & Gravity Offset Calculator

StellarShift is an interactive web utility designed for space exploration planners, worldbuilders, and science enthusiasts. It bridges astrophysics and daily scheduling by calculating gravitational time dilation, proper time drift, and synchronized solar day schedules (sols) across various interplanetary destinations.

## Features
- **Multi-Habitat Support**: Compare temporal metrics between Moon Base Alpha, Mars Colony, Europa Sub-Surface Outpost, Titan Hydrocarbon Station, and a Relativistic Starship.
- **Relativistic Starship Mode**: Configure custom cruise speeds (fraction of light speed) to calculate Lorentz time dilation factors and subjective crew aging vs. Earth elapsed time.
- **Gravity & Solar Day Metrics**: Compute exact local solar day lengths (sols) and surface gravity values relative to Earth.
- **Day-Night Cycle Synchronizer**: Interactive HTML5 canvas rendering planet day/night terminators and solar power generation curves synchronized with a 24-hour Earth time scrubber.
- **Multi-Planetary Meeting Overlap Window**: Automatically computes optimal communication sync intervals between Earth Command and remote off-world colonies.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No installation, build steps, or server dependencies required (fully static client-side application).

## Technology Stack
- Vanilla HTML5, CSS3, and JavaScript (ES6+)
- HTML5 Canvas 2D Context for astronomical visualizer
- 100% Client-side privacy with zero external network requests or tracking.
