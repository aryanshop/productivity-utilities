# AuraVelo: Bicycle Gear Ratio & Drivetrain Lab

A precision bicycle gear ratio, cadence speed, and drivetrain laboratory designed for cyclists, bike builders, mechanics, and commuters.

## Features

- **Customizable Drivetrain Setup**: Configure front chainrings, rear cassette cogs, tire dimensions, and pedalling cadence.
- **Preset Loadouts**: Quickly load standard setups like Road Compact (2x11), Gravel 1x, MTB Eagle (1x12), and Single Speed.
- **Speed & Gear Matrix**: Interactive speed and gear-inch matrix across all combinations.
- **Speed vs. Cadence Chart**: HTML5 Canvas visualization showing top and low gear speeds across cadences from 40 to 120 RPM.
- **Jump & Progression Analysis**: Evaluates percentage jumps between adjacent gears for cadence smoothness.
- **Unit Customization**: Switch easily between km/h and mph.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, package managers, or external servers required.

## Static Project Notice

This is a fully client-side static web application. All calculations run locally in your browser with zero data collection or external requests.
