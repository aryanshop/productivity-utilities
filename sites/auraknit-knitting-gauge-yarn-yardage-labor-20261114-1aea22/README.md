# AuraKnit: Knitting Gauge & Yarn Yardage Laboratory

AuraKnit is a precision knitting gauge conversion, yarn substitution, and yardage laboratory designed for fiber artists, knitters, and garment designers. It helps calculate exact cast-on stitch counts, row dimensions, yarn substitution requirements, and visualizations of stitch density without relying on external network services.

## Features

- **Garment & Project Calculator**: Configure pullovers, cardigans, scarves, hats, and socks with custom ease and dimensions.
- **Gauge Swatch Math**: Convert 4-inch (10cm) stitch and row swatches into exact garment measurements and stitch density ratings.
- **Yarn Substitution & WPI Estimator**: Compute required skeins, weight classes, and wraps-per-inch (WPI) equivalence.
- **Interactive Swatch Visualizer**: HTML5 Canvas rendering of knit V-stiches scaled to your exact gauge ratio.
- **Local Project Storage**: Save calculation sessions to browser `localStorage` and export backups as clean JSON files.

## Local Run Instructions

1. Download or clone the project files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` directly in any modern web browser.
3. Adjust input sliders and numeric parameters to instantly view recalculated knitting metrics.

## Technical Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- Zero external libraries, frameworks, trackers, or network dependencies.
- Fully client-side and privacy-first.
