# ChronoCraft: Pomodoro Task & Time-Block Architect

ChronoCraft is a comprehensive, privacy-first productivity workbench designed to help students, developers, and knowledge workers master their time, focus sessions, and daily task backlogs.

## Features

1. **Focus Timer (Pomodoro Studio)**:
   - Customizable Pomodoro (25m), Short Break (5m), and Long Break (15m) intervals.
   - Smooth circular SVG progress ring and browser title countdowns.
   - Web Audio API soft chime alerts upon session completion.
   - Direct binding to current tasks.

2. **Task Backlog & Priority Matrix**:
   - Create, filter (High, Medium, Low, Completed), and manage tasks.
   - Estimated pomodoro counts per task.
   - Local storage persistence.

3. **Daily Time-Blocking Schedule**:
   - Interactive hourly time-block planner from 6:00 AM to 11:00 PM.
   - Plan your day hour-by-hour seamlessly in the browser.

4. **Productivity Analytics**:
   - Track completed pomodoros, total focus hours, and finished tasks.
   - Interactive HTML5 Canvas weekly focus distribution chart.

## Local Run Instructions

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser.
3. No build tools, compilers, or external dependencies required.

## Technology Stack
- Vanilla HTML5, CSS3, and JavaScript (ES6+)
- HTML5 Canvas & Web Audio API
- LocalStorage for persistence
