# ChronoCraft: Visual Timeline & Milestone Dependency Architect

ChronoCraft is a privacy-first, offline-capable interactive project planning and timeline architect designed for creators, students, and project leads to map out complex multi-phase schedules without external servers or databases.

## Features

- **Task Dependency Engine**: Define predecessor-successor relationships and automatically calculate cascading timeline start offsets.
- **Interactive Task Breakdown**: Add, edit, toggle statuses (To Do, In Progress, Completed), and categorize tasks into functional phases (Research, Design, Development, QA, Launch).
- **Visual Gantt Chart View**: Dynamically rendered horizontal timeline with adjustable zoom scaling and color-coded phase bars.
- **Executive Summary Report**: Generates an automated project report with completion metrics, phase summaries, and milestone checklists ready for printing or PDF export.
- **JSON Export & Import**: Save your project configurations locally or share blueprint files with team members effortlessly.
- **Local Persistence**: Automatically caches your project state securely in browser local storage.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, package managers, or server connections are required as it runs completely standalone on client-side vanilla web technologies.

## Tech Stack

- HTML5, CSS3, Vanilla ES6 JavaScript
- Completely static client-side execution
