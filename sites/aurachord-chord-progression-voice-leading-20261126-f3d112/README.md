# AuraChord: Chord Progression & Voice Leading Workbench

AuraChord is a precision music theory, chord progression builder, and voice leading workstation designed for songwriters, composers, producers, and music students. Built completely client-side with zero external dependencies, it provides robust harmonic analysis and interactive audio feedback.

## Features

- **Interactive Key & Scale Selector**: Configure tonic roots across all 12 semitones and explore Major, Natural Minor, Harmonic Minor, Melodic Minor, Dorian, Mixolydian, and Pentatonic scales.
- **Diatonic & Borrowed Chord Palettes**: Instantly view diatonic triads and seventh chords within the active key, along with color chords (borrowed chords, secondary dominants).
- **Progression Sequence Builder**: Build, rearrange, and inspect chord sequences with individual chord previews and full loop playback.
- **Voice Leading & Harmonic Analysis**: Automatically calculates voice leading smoothness (semitone movement distance), cadence detection, and diatonic tonal stability ratios.
- **Canvas Keyboard Voicing Diagram**: Visualize exact piano keyboard voicings for any selected chord in real-time.
- **Web Audio API Polyphonic Synthesizer**: Choose between Sine, Triangle, Sawtooth, and Square synth voices with precise envelope control.
- **Local JSON Storage & Presets**: Save custom progression presets or export/import workspace JSON files.

## Running Locally

Simply open `index.html` in any modern web browser. No build steps or server required.
