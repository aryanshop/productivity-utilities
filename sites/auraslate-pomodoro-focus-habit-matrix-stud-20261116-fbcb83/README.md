# AuraSlate: Pomodoro Focus & Habit Matrix Studio

AuraSlate is a privacy-first, local-first productivity workspace designed for focused makers, developers, and professionals. It combines a customizable Pomodoro focus timer with an Eisenhower Priority Matrix and daily streak habit tracker.

## Features

- **Pomodoro Focus Timer**: Customizable work & break durations, animated visual progress ring, and Web Audio API chime notifications.
- **Eisenhower Priority Matrix**: Categorize tasks across four quadrants (Do First, Schedule, Delegate, Eliminate) with easy task linking to focus sessions.
- **Daily Habits Tracker**: Track recurring daily routines with streak counters and completion logs.
- **Local-First & Private**: All data is securely stored in your browser's `localStorage` with full JSON backup export and import capabilities.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enjoy a distraction-free, privacy-first productivity workspace!
