# AuraYield: Hydroponic Nutrient PPM & EC Mixing Laboratory

AuraYield is a precision hydroponic nutrient solution calculator and EC/PPM mixing workbench designed for indoor gardeners, greenhouse operators, and hydroponic hobbyists.

## Features
- **Reservoir & Source Water Configuration**: Configure water volume in US Gallons or Liters, set baseline source water EC, and choose PPM conversion scales (500, 700, or 640).
- **Crop & Growth Target Selector**: Tailor targets across multiple crops (Leafy Greens, Tomatoes, Cannabis, Herbs, Strawberries) and growth stages (Seedling, Vegetative, Bloom, Heavy Bloom) or input custom EC targets.
- **Nutrient Line Formulation Engine**: Supports popular commercial lines including General Hydroponics FloraSeries (3-Part), Advanced Nutrients Sensi (2-Part), Masterblend 4-18-38, and Canna Aqua.
- **Concentration Strength Multiplier**: Fine-tune dosage strength from 20% to 150% with real-time recalculation.
- **Visual Nutrient Ratio Balance Canvas**: HTML5 Canvas visualization showing constituent element proportions.
- **Mixing Protocol Safety Alerts**: Step-by-step mixing order instructions to prevent nutrient lockout and chemical precipitation.
- **Local Recipe Session Storage**: Save custom reservoir mixes and recall them instantly using browser LocalStorage.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser.
3. No build tools, external libraries, or server requirements needed. All calculations run entirely client-side.

## Static Project Notice
This project is built with vanilla HTML5, CSS3, and JavaScript with zero external network requests, dependencies, tracking cookies, or backend servers.
