# KnitCalc: Yarn Yardage & Gauge Needle Estimator

KnitCalc is a precision calculator and project planning tool designed specifically for knitters, crocheters, and fiber artists. It translates target project dimensions and gauge swatch measurements into exact yardage, skein counts, project weight, and cost breakdowns.

## Features

- **Project Type Presets**: Quick-load typical dimensions and gauges for scarves, hats, sweaters, cardigans, socks, blankets, and shawls.
- **Custom Dimensions**: Fully adjustable width, length, and custom gauge parameters (stitches and rows per 4 inches).
- **Yarn Weight & Skein Calculator**: Automatically computes total yardages, meters, skein counts with customizable safety buffers, estimated project weight in grams/ounces, and total material cost.
- **Stitch & Row Breakdown**: Calculates exact cast-on stitch counts, total rows to work, and cumulative individual stitches.
- **Proportional Canvas Preview**: Visualizes the project shape and proportions in real time.
- **Exportable Pattern Summary**: Generates a clean text summary ready to copy for your project notebook.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. No installation, server, or build steps required. Fully self-contained static app.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript.
- Responsive CSS Grid layout.
- HTML5 Canvas for live proportion rendering.
