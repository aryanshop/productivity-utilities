# StellarCal: Interplanetary Date & Ephemeris Time Converter

StellarCal is an advanced client-side interplanetary time conversion utility and astronomical ephemeris calculator designed for astronomers, sci-fi worldbuilders, and space mission planners.

## Features

- **Earth Baseline Control**: Input any Earth date and UTC time (or quickly sync to current time or J2000.0 epoch).
- **Planetary Chronologies**: Instantly calculate localized solar days (Sols), local clock times, and orbital years for Mars, the Moon, Venus, and Jupiter.
- **Mission Elapsed Timer (MET)**: Track mission elapsed time precisely from any custom launch epoch.
- **Light-Speed Signal Delay**: Calculate one-way communication signal transit times between Earth and destinations like Mars, Jupiter, Saturn, and Venus.
- **Astronomical Ephemeris & Canvas Simulator**: Compute Julian Dates, Modified Julian Dates, Greenwich Mean Sidereal Time (GMST), and view a live 2D inner solar system orbital configuration canvas.

## Local Run Instructions

1. Download or clone the repository.
2. Open `index.html` in any modern web browser.

*Note: This project is entirely static with zero external network requests or dependencies.*
