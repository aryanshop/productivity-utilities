# ZenFlow: Mindful Breathing & Somatic Coherence Studio

ZenFlow is a polished, distraction-free browser application designed for somatic nervous system regulation, mindful focus, and stress relief. Built with clean vanilla HTML5, CSS3, and modern JavaScript.

## Features

- **Science-Backed Breathing Patterns**: Choose between Box Breathing (4-4-4-4), 4-7-8 Deep Calm, Coherent Flow (5.5s / 5.5s), and Energizing Breath.
- **Fluid Visualizer**: Interactive SVG expanding/contracting breath guide with dynamic ambient glow and smooth CSS transitions.
- **Web Audio API Chimes**: Gentle harmonic tone generation providing auditory cues for breath transitions.
- **Session Tracking & Streaks**: Automatically tracks mindful minutes, completed sessions, and daily streaks locally in browser `localStorage`.
- **Somatic Reflection Journal**: Log post-session reflections and review recent entries.

## Local Run Instructions

1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Enjoy your mindfulness session. No build steps or server required!

## Privacy

ZenFlow operates entirely client-side. No data, journal entries, or audio telemetry leave your browser.
