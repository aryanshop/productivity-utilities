# AuraChord: Acoustic Frequency Interval & Tuning Temperament Laboratory

AuraChord is a precision musical acoustics and tuning temperament calculator designed for musicians, sound engineers, luthier instrument builders, and audio theorists. It allows users to explore how different historical tuning systems compare against standard Equal Temperament.

## Features
- **Multiple Tuning Systems**: Switch between 12-Tone Equal Temperament (12-TET), Just Intonation (Ptolemy's Diatonic), Pythagorean Tuning, and Meantone Temperament.
- **Interval Frequency Matrix**: Computes exact frequency ratios, exact Hz frequencies, and cent deviations for every musical interval from Unison to Octave.
- **Web Audio API Tone Generator**: Generate live audio oscillators (Sine, Triangle, Sawtooth) to hear root notes, interval notes, or harmonic dyads simultaneously to experience acoustic beating.
- **Cent Deviation Canvas Visualizer**: Graphical spread representation of temperament discrepancies relative to standard tuning.
- **Local-First Preset Storage**: Save, load, and manage your custom tuning sessions directly in browser local storage.

## Local Run Instructions
1. Download or clone repository files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` in any modern web browser.

*Note: This is a fully static client-side application with no external dependencies or tracking.*
