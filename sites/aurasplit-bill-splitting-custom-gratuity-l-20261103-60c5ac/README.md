# AuraSplit: Bill Splitting & Custom Gratuity Laboratory

AuraSplit is a precision bill splitting, shared expense, and custom gratuity workstation designed for group dinners, shared house expenses, travel trips, and complex dining checks. Built with privacy-first principles entirely client-side.

## Features
- **Comprehensive Bill Parameters**: Configure subtotal, sales tax, discounts, service fees, and custom event titles.
- **Flexible Gratuity Strategies**: Switch between percentage presets (15%, 18%, 20%, 22%, 25%), custom percentages, flat tip amounts, or no tip.
- **Tax & Tip Calculation Basis**: Choose whether gratuity is calculated on the pre-tax subtotal or post-tax grand total.
- **Participant Management**: Add, remove, and rename participants easily with quick-add helpers (+2, +4 guests).
- **Advanced Splitting Options**: Assign fractional shares (e.g. 0.5 or 2 shares) and custom individual item charges alongside shared costs.
- **Smart Rounding**: Choose exact cents, nearest whole dollar, or round-up rounding preferences.
- **Export & Copy**: Instantly copy a clean formatted text receipt summary to your clipboard or save sessions locally.

## Local Run Instructions
Since AuraSplit is a pure static web application with zero external dependencies, build tools, or servers:
1. Download or clone the repository.
2. Open `index.html` directly in any modern web browser.

## Tech Stack
- Vanilla HTML5
- Vanilla CSS3 (with CSS Custom Properties & Responsive Grid Layouts)
- Vanilla JavaScript (ES6+ with LocalStorage persistence)
