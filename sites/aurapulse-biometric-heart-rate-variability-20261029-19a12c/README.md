# AuraPulse: Biometric Heart Rate Variability & Recovery Rhythm Studio

AuraPulse is a local-first wellness and autonomic recovery utility designed to help remote workers, creators, and athletes monitor daily somatic readiness and regulate their nervous system through guided bio-rhythmic breathing.

## Features

1. **Daily Autonomic Check-in**: Log subjective sleep quality, muscle soreness, mental fatigue, and hydration levels to instantly compute a normalized Readiness Index score with actionable recovery recommendations.
2. **Resonance Breathing Studio**: Engage in paced 0.1Hz breathing protocols (Box breathing, Coherent 5.5s rhythm, 4-7-8 deep relaxation) with a fluid SVG expansion ring and Web Audio API ambient chime frequencies.
3. **Analytics & Streaks**: Track total session minutes, consecutive day streaks, and review historical recovery trends.
4. **Local-First JSON Backup**: Export and import your entire recovery history safely with browser localStorage persistence.

## Local Run Instructions

Simply download or clone the repository and open `index.html` in any modern web browser.

```bash
# Navigate to project directory and open index.html
open index.html
```

## Technical Stack

- Pure HTML5, CSS3, and Vanilla ES6+ JavaScript.
- Zero external libraries, frameworks, trackers, or network requests.
- Fully responsive and accessible design.
