# AuraSlate: Compound Interest & Inflation Wealth Simulator

AuraSlate is a precision financial growth and compound interest laboratory built with vanilla HTML, CSS, and JavaScript. It models long-term investment trajectories while factoring in inflation decay, recurring monthly contributions, tax drag, and horizon timelines.

## Features

- **Compound Growth Simulation:** Instantly calculate nominal vs. real (inflation-adjusted) portfolio values.
- **Interactive Canvas Visualizer:** Multi-line trajectory chart displaying Nominal Balance, Real Purchasing Power, and Total Principal contributions over time.
- **Year-by-Year Breakdown Table:** Detailed milestone tracking showing cumulative interest earned and purchasing power retention.
- **Local Scenario Presets:** Save, load, and manage custom financial scenarios securely in your browser's `localStorage`.
- **Zero External Dependencies:** Runs 100% locally with no telemetry, trackers, or network requests.

## Local Run Instructions

1. Download or clone the repository files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` directly in any modern web browser.
3. Adjust financial parameters in real time to simulate your personal wealth roadmap.

## Static Project Notice
This project is strictly a client-side static application designed for educational and personal financial visualization.
