# AuraPulse — Ergonomic Micro-Break & Posture Rhythm Architect

AuraPulse is a precision workspace wellness, deep work cadence planner, and micro-break rhythm architect designed for desk workers, programmers, and remote professionals. Built with a privacy-first, local-first architecture using vanilla HTML5, CSS3, and modern JavaScript.

## Features

1. **Rhythm Studio & Visual Timer**:
   - Customizable work-to-break intervals (Pomodoro 25/5, Ultradian 50/10, Deep Flow 90/20, Micro Reset 15/3).
   - Animated SVG circular progress ring timer with real-time countdown formatting.
   - Web Audio API custom sine-wave chimes signaling work and break transitions.

2. **Somatic Stretch & Eye-Strain Relief Library**:
   - Curated desk exercises targeting cervical neck retractions, upper trapezius tightness, wrist flexor/extensor care, 20-20-20 visual acuity resets, and thoracic spinal alignment.
   - Interactive category filtering chips and step-by-step execution protocol modals.
   - Dynamic break prescription prompts that suggest contextual stretches during rest intervals.

3. **Analytics & Local-First Session Logging**:
   - Tracks total focus minutes, completed work cycles, and micro-breaks taken.
   - Persistent local storage integration.
   - JSON export and local history management.

## Local Run Instructions

Since this is a fully static client-side web application, no build tools, package managers, or server runtimes are required:

1. Clone or download the repository files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).

## Technology Stack

- **HTML5**: Semantic document structure with accessibility considerations.
- **CSS3**: Custom variables, responsive Grid & Flexbox layouts, smooth CSS transitions, and SVG circular progress animations.
- **JavaScript (ES6+)**: Modular state management, Web Audio API synthesis, local storage data persistence, and dynamic DOM rendering.
- **Zero External Dependencies**: No external frameworks, remote fonts, tracking scripts, or external network requests.
