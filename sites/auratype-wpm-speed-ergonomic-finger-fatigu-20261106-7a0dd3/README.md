# AuraType: WPM Speed & Ergonomic Finger Fatigue Lab

AuraType is a precision typing speed analytics, finger fatigue, and ergonomic keystroke distribution workstation designed for touch typists, programmers, and copywriters.

## Features
- **Live Typing Speed & Accuracy Test**: Practice across prose, JavaScript/code snippets, and symbol-heavy syntax with real-time WPM, accuracy, and countdown timer tracking.
- **Interactive Keystroke Heatmap**: Visualizes real-time finger stress and key frequency across a responsive virtual keyboard layout.
- **Ergonomic Finger Fatigue Matrix**: Computes left/right hand balance ratios, home row retention percentages, row stretch frequency, and postural feedback recommendations.
- **Targeted Finger Drill Generator**: Custom training drills focused on weak fingers (pinkies, rings, middles) and programming symbols.
- **Local Session Logging**: Securely stores past typing sessions in browser local storage with JSON export capabilities.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Click on the typing prompt area or start typing to begin.

## Technology Stack
- Pure Vanilla HTML5, CSS3, and JavaScript.
- No external frameworks, build tools, CDNs, or network requests.
- Client-side storage via localStorage.
