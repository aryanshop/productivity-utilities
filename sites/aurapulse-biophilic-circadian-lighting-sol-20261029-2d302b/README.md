# AuraPulse: Biophilic Circadian Lighting & Solar Arc Studio

AuraPulse is an interactive biophilic lighting and circadian rhythm design workstation for remote workers, designers, and home office planners.

## Purpose & Features
- **Solar Arc Simulation**: Interactive canvas rendering real-time sun trajectories, azimuth angles, and sky gradients throughout the day.
- **Circadian Illuminance Metrics**: Computes biological melanopic lux (mEDI) and Correlated Color Temperature (CCT in Kelvin) relative to window orientation, room depth, and shading.
- **Shift-based Prescription**: Automatically generates custom circadian lighting schedules and phase targets for optimal daytime focus and evening wind-down.
- **JSON Export**: Export your customized room lighting prescription instantly.

## Local Run Instructions
1. Save all project files (`index.html`, `style.css`, `script.js`, `README.md`) in the same directory.
2. Open `index.html` in any modern web browser.
3. Adjust sliders, time scrubber, and window parameters to simulate your workspace environment.

## Technology Stack
- Pure vanilla HTML5, CSS3, and JavaScript (ES6+).
- Zero external libraries, frameworks, or network requests.
