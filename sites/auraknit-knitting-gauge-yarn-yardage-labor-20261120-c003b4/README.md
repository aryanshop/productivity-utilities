# AuraKnit: Knitting Gauge & Yarn Yardage Laboratory

AuraKnit is a precision knitting gauge conversion, yarn substitution, and yardage laboratory designed for fiber artists, knitters, and garment designers.

## Features

- **Garment & Ease Calculations**: Compute exact cast-on stitch counts and row heights based on bust/chest measurements and positive/negative ease.
- **Swatch Gauge Converter**: Convert 4-inch / 10cm swatch measurements into precise project specifications.
- **Yarn Weight & Substitution Guide**: Reference WPI (wraps-per-inch) ranges and standard needle sizes across Lace to Super Bulky yarn categories.
- **Interactive Stitch Counter**: Track your ongoing row or stitch count with instant increment/decrement controls.
- **Visual Gauge Grid**: HTML5 Canvas visualization rendering the proportion grid of your swatch.
- **Local Project Storage**: Save your project calculations to local storage or export as a JSON backup file.

## Local Run Instructions

1. Download or clone all repository files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` directly in any modern web browser.

*AuraKnit is 100% static, client-side, and privacy-first with zero external dependencies or network requests.*
