# AuraVane: Airfoil & Wind Turbine Power Coefficient Laboratory

## Overview
AuraVane is a precision aerodynamics and renewable energy workbench designed for green energy enthusiasts, student engineers, turbine hobbyists, and DIY makers. It computes real-time aerodynamic equations, Betz limit performance bounds, tip speed ratios (TSR), swept areas, and electrical power generation metrics entirely client-side.

## Features
- **Environmental Modeling:** Configure wind speed, air density, and ambient temperatures.
- **Rotor Geometry Workbench:** Adjust blade radius, blade count, pitch angles, and rotational speed (RPM).
- **Generator & Transmission Specs:** Calculate losses across generator efficiency ratings and nominal DC/AC system voltages.
- **Interactive Canvas Visualizations:**
  - Real-time animated turbine rotor and airflow vector studio.
  - Dynamic Power Output vs. Wind Speed curve plotting.
- **Engineering Diagnostics:** Automated optimization feedback and recommendations based on Tip Speed Ratio (TSR) and Power Coefficient ($C_p$).
- **Local Data Export:** Instantly export simulation sessions to JSON format.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No build tools, external servers, or package installations required.

## Privacy & Architecture
Built with vanilla HTML5, CSS3, and modern JavaScript. All calculations run strictly in your browser with zero external requests, cookies, tracking, or telemetry.
