# AuraCalc: Pixel Art & Viewport Scale Laboratory

A precision pixel art canvas dimension, sprite scaling, and responsive viewport aspect ratio laboratory built with vanilla HTML5, CSS3, and JavaScript.

## Purpose & Features

- **Retro Console Presets**: Quickly load authentic standard dimensions for Game Boy (160x144), NES (256x240), SNES (256x224), PICO-8 (128x128), and custom tile sizes.
- **Integer Scaling Multipliers**: Calculates exact integer upscale bounds to guarantee crisp, distortion-free pixel rendering without sub-pixel blur or artifacts.
- **Interactive Pixel Inspector**: Switch to the Inspector view to paint and edit test patterns directly on a live pixel grid with multiple retro color palettes (Game Boy, PICO-8, Cyberpunk, Monochrome).
- **Responsive Viewport Simulation**: Simulates letterboxing, aspect fit, and stretch modes against target display resolutions ranging from standard desktop monitors to 4K displays.
- **CSS Code Synthesizer**: Instantly generates ready-to-copy CSS snippets enforcing `image-rendering: pixelated`.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enjoy a 100% client-side offline laboratory experience with zero external dependencies or network calls.
