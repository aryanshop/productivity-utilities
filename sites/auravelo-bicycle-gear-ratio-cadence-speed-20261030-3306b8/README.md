# AuraVelo: Bicycle Gear Ratio & Cadence Speed Lab

AuraVelo is a precision drivetrain calculation and gear ratio workbench designed for cyclists, bike builders, commuters, and mechanics. It allows users to compute exact speeds, development metrics, gear inches, and jump percentages across any combination of chainrings and cassette cogs.

## Features

- **Drivetrain Customization**: Input custom chainring and cassette tooth counts with instant chip parsing.
- **Wheel Size Profiles**: Choose standard road (700c), mountain (29", 27.5", 26"), BMX, or custom perimeter dimensions in millimeters.
- **Cadence Simulator**: Real-time slider to test speeds from 50 to 130 RPM.
- **Interactive Canvas Speed Matrix**: Visualizes speed curves across cassette cogs for each chainring.
- **Comprehensive Data Table**: Lists gear ratios, gear inches, development distance in meters, speed at target cadence, and gear step percentage progression.
- **Preset Drivetrains**: Instantly load popular configurations such as Road Endurance 2x11, Gravel 1x12, Modern MTB 1x12, Urban Commuter 3x8, and Fixed Gear.

## Local Run Instructions

Clone or download this repository and open `index.html` in any modern web browser. No build steps, dependencies, or server setup required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+)
- HTML5 Canvas for data visualization
- Responsive, accessible, and privacy-first (Zero data collection or cookies)
