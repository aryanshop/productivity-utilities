# AuraVane: Thermal Insulation & Vapor Barrier Dew Point Calculator

AuraVane is a precision thermal building science laboratory designed for architects, home energy auditors, insulation contractors, and DIY renovators. It computes boundary temperature gradients, U-factors, total R-values, and interstitial condensation risks across multi-layer wall assemblies.

## Features

- **Multi-Layer Wall Assembly Editor**: Configure layers from interior air film to exterior cladding, including fiberglass batts, XPS/EPS rigid foam, polyisocyanurate, drywall, OSB, and vapor barriers.
- **Preset Wall Assemblies**: Instantly load standard 2x4 wall configurations or modern exterior continuous insulation wall designs.
- **Dew Point & Condensation Analysis**: Uses the Magnus formula to calculate dew point thresholds and highlights critical condensation risk zones.
- **Interactive Canvas Gradient Graph**: Visually inspect the temperature drop curve across each wall layer against the constant dew point threshold.
- **JSON Report Export**: Download your complete wall assembly simulation and environmental parameters for local record keeping.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. Adjust environmental inputs or wall layers to test thermal performance instantly.

## Technical Note

This is a 100% static client-side web application. No external frameworks, libraries, fonts, or network requests are utilized.
