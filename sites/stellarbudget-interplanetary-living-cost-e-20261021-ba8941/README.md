# StellarBudget: Interplanetary Living Cost & Expense Optimizer

StellarBudget is a futuristic personal finance simulator and budgeting tool designed for citizens planning their financial freedom across various interstellar destinations (Earth, Mars Colony, Lunar Base, Titan Outpost, and Orbital Space Stations).

## Features
- **Interplanetary Cost Scaling**: Select between 5 distinct celestial colonies, each featuring unique gravity multipliers, taxation rates, and atmospheric maintenance costs.
- **Interactive Expense Matrix**: Configure income streams, dome rent, life support utilities, ration synthesizers, and colony taxes.
- **Visual Economic Breakdown**: Real-time progress bars displaying expense distribution and share of income.
- **AI Colony Financial Advisor**: Dynamic contextual feedback advising you on living cost optimizations.
- **Compound Growth Projections**: Interactive HTML5 Canvas chart tracking your savings and 6% APR compound investment yields over a 1 to 30-year horizon.
- **Emergency Contingency Stress-Test**: Simulate unexpected cosmic events (like solar flare storm damage) to test your financial resilience.

## Local Run Instructions
1. Clone or download the repository files (`index.html`, `style.css`, `script.js`, `README.md`).
2. Open `index.html` directly in any modern web browser.
3. Adjust financial parameters or select new colony destinations to instantly recalculate your futuristic ledger.

## Technology Stack
- Pure vanilla HTML5, CSS3, and JavaScript.
- Zero external dependencies, build tools, network requests, or tracking trackers.
