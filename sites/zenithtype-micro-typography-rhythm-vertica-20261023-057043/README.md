# ZenithType: Micro-Typography Rhythm & Vertical Rhythm Grid Calculator

ZenithType is an interactive micro-typography workbench and vertical rhythm calculator designed for web developers, designers, and typographers. It enables precise creation and previewing of modular typographic scales synchronized with a baseline grid.

## Features

- **Modular Typography Scaling**: Configure base font size and choose from standard ratios (Minor Third, Golden Ratio, Perfect Fourth, etc.) to instantly calculate proportional font sizes from caption to display levels.
- **Vertical Rhythm Synchronization**: Adjust base line-heights and baseline grid units with live rhythm scoring that alerts you to perfect grid snapping.
- **Interactive Editorial Preview Canvas**: Test your typography live across simulated Desktop, Tablet, and Mobile viewports with a toggleable baseline grid overlay.
- **CSS Token Exporter**: Instantly generate and copy clean production-ready CSS custom properties for your projects.
- **Privacy First**: 100% client-side vanilla web application with zero external requests, tracking, or dependencies.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. Adjust typography controls in the sidebar and explore live changes on the preview workspace.
