# AeroGrid: Workspace Desk Cable & Power Load Optimizer

AeroGrid is a precision desk power load calculator and cable routing planner designed for remote workers, developers, and desktop enthusiasts. It helps you prevent circuit overloads, estimate electricity running costs, visualize power strip plug congestion, and organize your workspace cables cleanly.

## Features

- **Live Power & Amperage Calculations:** Instantly calculates total wattage, circuit amperage draw across 120V/230V options, and estimated monthly electricity bills.
- **Interactive Hardware Inventory:** Add, customize, and manage your monitors, computers, audio interfaces, charging bricks, and lighting with instant category color-coding.
- **Top-Down Desk & Power Strip Visualizer:** Visualize power brick congestion across 8-outlet surge protector slots and view connected hardware distribution.
- **Electrical Safety & Cable Audit:** Automated safety checks for continuous load thresholds, cable length totals, and brick density warnings.
- **Shopping & Organization Blueprint:** Generates a customized shopping checklist for surge protectors, cable trays, and management accessories.
- **Quick Presets:** Instantly load Minimalist Laptop, Power Dev Rig, or Content Creator workstation profiles.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No installation, build tools, or network connections are required.

## Technologies

- Pure HTML5, CSS3, and Vanilla JavaScript.
- Fully responsive layout optimized for desktop and mobile workstations.
- 100% client-side functionality with zero external dependencies or tracking.
