# AeroGear: Backpack Pack Weight & Volume Distribution Analyzer

AeroGear is a comprehensive, client-side web utility built for backpackers, hikers, and travel enthusiasts to meticulously plan and optimize their pack loadout.

## Features

- **Weight & Volume Calculation**: Instantly computes base weight, total pack weight, and total packed volume in liters.
- **Unit Flexibility**: Seamlessly toggle between Metric (grams/kg, liters) and Imperial (ounces/pounds, liters).
- **Pack Capacity Meter**: Compare total volume against common pack sizes (Daypack 35L up to Expedition 85L) with color-coded warning thresholds.
- **Comfort Rating System**: Automated load analysis providing instant feedback from Ultralight agility to Heavy load warnings.
- **Category Filters & Presets**: Quickly test pre-configured Ultralight or Weekend setups or filter items by category (Shelter, Sleep, Kitchen, Wear, Misc).
- **Export & Print**: Export your complete gear blueprint as a JSON file or print a clean gear checklist directly from the browser.

## Local Run Instructions

1. Download or clone all repository files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser.
3. No server setup or external dependencies required; everything runs 100% locally and securely in your browser.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- No external frameworks, build tools, or network requests.
