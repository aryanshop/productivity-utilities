# AuraBrew: Specialty Coffee Extraction & Ratio Lab

AuraBrew is a precision coffee brewing calculation and extraction lab designed for baristas, home brewers, and specialty coffee enthusiasts. It allows you to dial in your bean dose, water ratios, grind size, and extraction metrics across popular brewing methods.

## Features
- **Multiple Brewing Methods**: Optimized presets for Hario V60, Chemex, French Press, AeroPress, Espresso, and Cold Brew.
- **Precision Extraction Formulas**: Calculates exact water weight, estimated Total Dissolved Solids (TDS), and extraction yield percentages.
- **Interactive Stopwatch & Pour Schedule**: Real-time timer with step-by-step pour cues and target water volume milestones.
- **Brew Journal**: Save your favorite bean recipes, tasting notes, and ratings locally in your browser.

## Running Locally
Simply clone or download this repository and open `index.html` in any modern web browser. No build steps, frameworks, or internet connection required.
