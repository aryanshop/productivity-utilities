# AuraSlate: Semantic Markdown Kanban & Focus Sprint Board

AuraSlate is a privacy-first, local-first Kanban task board and Markdown productivity workspace built for solo makers, writers, and knowledge workers. It combines seamless drag-and-drop workflow management with rich Markdown task notes and an integrated Pomodoro focus timer.

## Features

- **5-Column Kanban Board**: Backlog, To Do, In Progress, Review, and Done columns with smooth HTML5 drag-and-drop card movement.
- **Rich Markdown Notes & Preview**: Write task descriptions using Markdown headings, lists, bold/italic formatting, and toggle a live HTML preview.
- **Integrated Pomodoro Focus Timer**: Built-in 25-minute focus and 5-minute break timer with audio-visual notifications and title bar countdown tracking.
- **Search, Priority & Tag Filtering**: Instantly filter tasks by search keywords, priority levels (Low, Medium, High), and custom tags.
- **Local-First & Secure**: All tasks and settings are securely stored in your browser's `localStorage` with zero server requests or external tracking.
- **Backup & Restore**: Easily export your entire workspace to a JSON file or import backups whenever needed.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No build tools, package managers, or server connections required!

## Technology Stack

- Vanilla HTML5 / Semantic Markup
- Modern CSS3 Grid & Flexbox with Custom Properties
- Vanilla ES6 JavaScript (No frameworks or external libraries)
