# AuraPulse: Ergonomic Micro-Break & Posture Rhythm Architect

AuraPulse is an original, privacy-first productivity and wellness utility designed for remote workers, developers, and designers who spend long hours at their desks. It merges customizable deep work focus intervals with guided somatic desk stretches, 20-20-20 eye strain prevention timers, and generative Web Audio API soundscapes.

## Features

1. **Pulse Timer & Focus Architect**: Customize Deep Flow, Micro-Breaks, and 20-20-20 Eye Rest sessions with smooth SVG animated countdown rings.
2. **Somatic Desk Stretches**: Filterable guide for neck, spine, and wrist stretches to alleviate seated fatigue.
3. **Generative Ambient Soundscapes**: Procedural white noise rain, coastal waves, alpha binaural beats (10Hz), and forest synth pads powered entirely by the Web Audio API without external audio files.
4. **Flow Analytics & Streaks**: Track daily focus sessions, completed micro-breaks, and weekly distribution charts.
5. **Client-Side Persistence**: Fully local-first using `localStorage` with zero external dependencies, tracking, or network requests.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Enjoy focus pacing and ergonomic wellness instantly!
