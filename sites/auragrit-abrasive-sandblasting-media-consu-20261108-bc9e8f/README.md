# AuraGrit: Abrasive Sandblasting & Media Consumption Lab

AuraGrit is a professional, client-side surface preparation and industrial blasting calculator. It helps metalworkers, restorers, fabricators, and woodworkers accurately estimate abrasive media consumption, required air compressor CFM, nozzle exit velocities, and blast run times.

## Features
- **Comprehensive Media Database**: Select from Glass Bead, Aluminum Oxide, Garnet, Walnut Shell, and Steel Shot with embedded hardness and recycling coefficients.
- **Substrate & Coating Adjustments**: Accounts for structural steel, aluminum, hardwood, and masonry alongside coating removal severity (light mill scale to heavy epoxy).
- **Air Compressor CFM Estimator**: Computes continuous air delivery requirements based on standard nozzle orifice sizes (#2 through #8) and operating pressure (PSI).
- **Local Session Logging**: Save calculation snapshots to browser local storage for future reference or project costing.

## Local Run Instructions
1. Download or clone repository.
2. Open `index.html` directly in any modern web browser.
3. Fully static project requiring no build tools, server setup, or external dependencies.
