# AuraStrap: Ergonomic Watch Strap Sizing & Lug Geometry Laboratory

AuraStrap is a precision horological engineering and leathercraft workbench designed for watch collectors, custom strap makers, horologists, and DIY modders. It computes optimal strap geometries, proportions, hole spacings, and leather blank cutting blueprints based on wrist circumference and watch case specifications.

## Features

- **Ergonomic Sizing Algorithm**: Computes exact short and long strap piece lengths for any wrist size and watch lug-to-lug span.
- **Interactive Blueprint Canvas**: Visualizes precise top-down layouts, tapers, spring bar cutouts, and sizing hole positions.
- **Customizable Parameters**: Adjust lug widths, buckle widths, material thickness, keeper configurations, and tail shapes.
- **Local-First Storage**: Automatically saves session state to `localStorage` so your configuration is retained between visits.
- **JSON Specification Export**: Instantly export your strap blueprint and dimensions as a clean JSON file for leathercraft templates or workshop notes.

## Local Run Instructions

This is a static client-side web application built with vanilla HTML5, CSS3, and modern JavaScript. No build tools, package managers, or server runtimes are required.

1. Download or clone the repository.
2. Open `index.html` directly in any modern web browser (Chrome, Firefox, Safari, Edge).

## Technology Stack

- **HTML5 Semantic Markup**
- **CSS3 Flexbox, CSS Grid & Custom Properties**
- **HTML5 Canvas 2D Rendering Engine**
- **Native Browser LocalStorage API & Blob Export**

*No external scripts, fonts, tracking analytics, or network requests are used.*
