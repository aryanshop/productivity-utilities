# AuraCalc: Compound Interest & Inflation Wealth Simulator

AuraCalc is a precision wealth accumulation and inflation-adjusted retirement growth simulator built for long-term investors, planners, and savers. Designed with a privacy-first, local-first approach using vanilla HTML, CSS, and JavaScript.

## Features

- **Compound Growth Simulation**: Calculate nominal and real purchasing power over custom time horizons (up to 50 years).
- **Inflation & Tax Drag Adjustments**: Account for inflation and estimated investment tax drag.
- **Interactive HTML5 Canvas Chart**: Visually inspect portfolio trajectory, total principal contributions, and real purchasing power growth.
- **Yearly Breakdown Table**: Detailed ledger showing cumulative interest earned and year-by-year valuations.
- **Preset & JSON Management**: Save your simulation parameters locally in browser storage or export them as JSON backups.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No server setup or external dependencies required.

## Static Project Notice

This is a 100% static client-side web application. No external network requests, third-party libraries, tracking, or telemetry are used.
