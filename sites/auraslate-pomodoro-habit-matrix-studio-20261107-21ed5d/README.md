# AuraSlate: Pomodoro & Habit Matrix Studio

AuraSlate is a precision privacy-first productivity studio designed for knowledge workers, students, and indie makers. It combines a robust Pomodoro focus timer, a daily habit tracker with streak counters, and an Eisenhower Priority Matrix into a single polished workspace.

## Features

- **Focus Sprint Timer**: Customizable Pomodoro (25m), Short Break (5m), and Long Break (15m) intervals with an animated SVG progress ring and Web Audio API chime alerts.
- **Eisenhower Priority Matrix**: Organize tasks into four quadrants (Do First, Schedule, Delegate, Eliminate) and assign tasks directly to your active focus session.
- **Daily Habit Tracker**: Build consistency with daily habit toggles and streak tracking.
- **Local-First & Secure**: All data is securely stored in your browser's `localStorage` with zero external requests, trackers, or cookies.
- **Backup & Restore**: Easily export your entire workspace to a local JSON file or import backups anytime.

## Local Run Instructions

1. Download or clone the project repository.
2. Open `index.html` directly in any modern web browser.
3. That's it! No build steps, servers, or external dependencies are required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- Web Audio API for audio feedback.
- SVG for circular timer progress animations.
