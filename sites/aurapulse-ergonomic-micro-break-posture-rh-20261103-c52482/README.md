# AuraPulse: Ergonomic Micro-Break & Posture Rhythm Architect

AuraPulse is a privacy-first workspace wellness and micro-break rhythm planner designed for desk workers, programmers, and remote professionals. It blends deep focus intervals with somatic desk stretches and eye-strain relief prompts.

## Features
- **Rhythm Management**: Customizable focus blocks (e.g., 25/5 Pomodoro or 50/10 Ultradian rhythms) with animated SVG circular progress indicators.
- **Somatic & Eye Guides**: Curated movement prompts for neck, spine, wrists, and vision care.
- **Web Audio API Feedback**: Gentle ambient audio chimes signal transitions between work and break periods without abrupt alarms.
- **Local Movement Log**: Tracks completed focus sessions, minutes accumulated, and daily streaks locally via `localStorage`.
- **Zero Tracking**: 100% client-side vanilla web app with no external telemetry or network requests.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.

## Static Project Note
This project is fully self-contained using vanilla HTML5, CSS3, and modern JavaScript.
