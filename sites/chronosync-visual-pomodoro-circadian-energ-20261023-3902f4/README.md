# ChronoSync: Visual Pomodoro & Circadian Energy Aligner

ChronoSync is a privacy-first web utility designed for remote workers, developers, and students who want to harmonize their structured Pomodoro work sessions with their natural biological energy curves.

## Features

- **Precision Pomodoro Timer**: Switch between Deep Focus (25m), Short Break (5m), and Restoration (15m) intervals with live animated circular progress feedback and browser title updates.
- **Circadian Energy Aligner**: Interactive HTML5 Canvas visualization mapping 24-hour cognitive energy curves adjusted for your personal chronotype (Bear, Lion, Wolf, Dolphin), complete with realtime window recommendations.
- **Session Focus & Energy Logger**: Record completed tasks, rate post-session cognitive energy levels, and track distraction counts.
- **Local Ledger & Analytics**: Automatically stores daily sessions securely in your browser's local storage with summary metrics.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No installation, build steps, servers, or external network requests required.

## Architecture

Built entirely with vanilla HTML5, CSS3, and modern JavaScript (ES6+). Designed to be clean, accessible, and fully responsive across mobile and desktop devices.
