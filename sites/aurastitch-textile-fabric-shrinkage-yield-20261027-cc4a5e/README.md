# AuraStitch: Textile Fabric Shrinkage & Yield Estimator

AuraStitch is a precision sewing, tailoring, and textile yardage calculator designed for garment makers, quilters, and DIY crafters. It calculates exact fabric requirements, pre-wash shrinkage allowances, pattern matching waste percentages, and grainline yield optimization.

## Features
- **Fabric Width Selection**: Choose standard roll widths (44", 54", 60", 72").
- **Shrinkage Allowance Calculations**: Compute warp (length) and weft (width) post-wash shrinkage factors.
- **Project Piece Inventory**: Add, customize, and manage individual garment panels with quantities and dimensions.
- **Preset Loaders**: Instantly load typical shirt or trouser pattern piece inventories.
- **Visual Layout Simulator**: Live HTML5 Canvas rendering of nesting approximations across fabric rolls.
- **Cost & Yield Analysis**: Calculates raw cut yardage, recommended buy yardage rounded to quarter-yards, and total project fabric costs.
- **Export & Print**: Save project configurations as JSON or generate clean print layouts.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No installation, build steps, or internet connection required (100% client-side vanilla JavaScript, HTML5, and CSS3).

## Privacy
All calculations run entirely inside your browser. No data or project lists are uploaded or stored externally.
