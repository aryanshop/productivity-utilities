# AuraChord: Resonant Chime & Solfeggio Tone Generator

AuraChord is a precision acoustic frequency and Solfeggio tone generator workspace designed for deep focus, meditation, binaural beat entrainment, and sonic relaxation. Built with vanilla HTML5, CSS3, and JavaScript, it harnesses the native browser Web Audio API to deliver pure oscillator frequencies without external dependencies or cloud requests.

## Features

- **Solfeggio & Harmonic Presets**: Instantly switch between classic sacred frequencies (432 Hz Earth tone, 528 Hz DNA repair/transformation, 396 Hz liberation, 639 Hz connection, 741 Hz intuition, and 852 Hz spiritual order).
- **Carrier & Binaural Entrainment Controls**: Fine-tune carrier frequencies and binaural offsets (Delta, Theta, Alpha, Beta, Gamma brainwave states) with real-time frequency calculations for left and right channels.
- **Harmonic Overtones & Waveform Synthesis**: Choose between Pure Sine, Warm Triangle, or Rich Sawtooth waveforms with optional overtone chorus resonance.
- **HTML5 Canvas Oscilloscope**: Real-time visualizer rendering audio waveforms.
- **Focus Session Timer**: Integrated countdown timer (10m, 25m, 45m, 60m) with automatic audio stop upon completion.
- **Local-First Preset Manager**: Save customized sonic setups directly to browser `localStorage`.

## Local Run Instructions

1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. Click **Start Sound Generation** to begin listening (ensure your device volume is adjusted to a comfortable listening level).

## Technology Stack

- Pure Vanilla JavaScript (ES6+)
- Web Audio API (AudioContext, Stereo Merging, Oscillators, AnalyserNode)
- HTML5 Canvas
- CSS Custom Properties & Responsive Grid Layouts

*AuraChord is 100% static and privacy-first. No tracking, analytics, or external network requests are made.*
