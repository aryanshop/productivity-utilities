# AeroPitch: Acoustic Room Resonance & Speaker Placement Calculator

## Overview
AeroPitch is a professional acoustic calculation workbench built for home studio owners, mixing engineers, and acoustic designers. It computes low-frequency axial standing waves (room modes), Speaker-Boundary Interference Response (SBIR), Schroeder frequency thresholds, and optimal speaker/listener geometries.

## Features
- **Room Mode Calculator**: Computes axial standing wave frequencies up to 300Hz across Length, Width, and Height axes.
- **Schroeder Frequency Estimator**: Determines the transition frequency where modal resonance yields to diffuse reverberation.
- **Interactive Room Top-Down Map**: Visualizes recommended equilateral speaker triangle placement and 38% sweet-spot listening coordinates.
- **SBIR Calculator**: Calculates boundary reflection cancellation notches for front walls, side walls, and floor bounces.
- **Acoustic Treatment Report**: Generates a clean technical summary with bass trapping and panel placement guidelines.

## Local Run Instructions
Simply open `index.html` in any modern web browser. No build tools, package managers, or internet connection required.

## Technical Stack
- Pure HTML5, CSS3, and Vanilla JavaScript.
- Responsive CSS Grid and Flexbox layout.
- HTML5 Canvas for interactive acoustic visualizations.
