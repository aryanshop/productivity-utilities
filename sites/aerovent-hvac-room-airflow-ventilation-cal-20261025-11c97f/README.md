# AeroVent: HVAC Room Airflow & Ventilation Calculator

AeroVent is an interactive engineering and room ventilation planning utility designed to calculate precise airflow requirements (CFM), air changes per hour (ACH), and air purifier CADR specifications based on room dimensions and ASHRAE occupancy standards.

## Features

- **Comprehensive Calculations**: Instantly computes room volume, required CFM, ACH standards, and recommended air purifier CADR.
- **Multiple Occupancy Profiles**: Select from Home Offices, Living Rooms, Commercial Kitchens, Workshops, Bathrooms, and Gyms.
- **Unit System Toggle**: Seamlessly switch between Imperial (Feet, CFM) and Metric (Meters, m³/h) measurements.
- **Interactive Airflow Simulation**: Live HTML5 canvas particle simulation illustrating room air circulation from supply to return vents.
- **Ventilation Insights**: Dynamic recommendations and best practices for acoustic and duct balance.

## Local Run Instructions

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. No installation, build steps, or server required.

## Technology Stack

- Pure Vanilla HTML5, CSS3, and JavaScript.
- Responsive CSS Grid and Flexbox layout.
- HTML5 Canvas 2D graphics for real-line airflow particle animation.
- 100% offline and privacy-friendly with zero external dependencies or tracking.
